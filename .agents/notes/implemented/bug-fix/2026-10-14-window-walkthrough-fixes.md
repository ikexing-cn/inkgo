# Agent Note: 在真窗口里点一遍找到的问题：Esc 退不出查找、跳到下一处弹出选区浮条、专注模式丢键盘、深色下的遮罩看不出

Status: implemented

## Problem

作者 2026-10-14：「我希望你现在使用computer use（kimi）的进行自动化检测和优化，能做的都先做，主要负责UI/UX改进还有BUG修复架构调整……第二天向我汇报。」于是把 `cmd/poc` 编出来，在隔离的目录里（另设 `APPDATA`、`USERPROFILE`，用 `cmd/sample` 的两本书）开真窗口，用鼠标键盘一处处点。headless 测试按不到、或者没想到去按的，这里找到了这几处：

1. **查找框里按 Esc 不关查找条。** 原型 `app.js` 的 `backOut` 里 Esc 会关掉查找；写作软件里只有点 ✕ 才关。
2. **在查找框里回车跳到下一处，正文上面弹出「AI 改写 / 加入设定」的浮条**，盖住上一行。跳到哪一处就选中哪一处，选区浮条见选区就出来；原型里查找的高亮不是选区，不弹。
3. **按了 Esc 选区还在。** 原型的 `backOut` 最后一级是取消选中、收起浮条；写作软件里正文没有 AI 的续写建议时，Esc 什么都不做。
4. **F11 进专注模式，正文丢了键盘。** 光标还画着，打字没反应，要再点一下正文。藏起侧栏也一样。mygo 按「父元素 + 在兄弟里的位置（或 key）」认元素：专注模式不画标题栏和侧栏，正文所在的那一列在兄弟里的位置变了，被当成新元素，焦点跟着旧元素没了。
5. 关查找条的写法散在五处（✕、工具栏的放大镜、开始 AI 改写、开始起草、开始记伏笔），后三处只把 `finding` 置假，没有清掉正文里查找的黄色高亮，也没有收起「全书」。
6. **深色下对话框后面没有遮罩。** `--scrim` 只有一个值 `rgba(25,25,25,.32)`，深色的底正好是 `#191919`，盖上去颜色不变；深色的对话框底 `#222221` 和后面的页面也只差一点，设置窗口像是贴在页面上。原型共用这份 `tokens.css`，一样。

## Decision

- **一个 `closeFind`**：收起查找条、收起「全书」和全书替换的确认、清掉正文里的高亮。上面五处都调它。
- **Esc 按原型的先后退**：查找条开着，先关查找条，键盘回到正文（找到的那一处仍选中）；查找条关着、正文有选区，再按一次取消选中（光标留在原处），浮条跟着没了。写在写作页的窗口级快捷键里（`c.Shortcut`），所以焦点在查找框里、在正文里都管用；正文里有续写建议时 Esc 先由编辑器收掉建议，改名框、各个小面板里的 Esc 由它们自己的输入框先拿到，不受影响。
- **查找条开着、焦点不在正文时不出选区浮条**：在查找框里回车或点上下箭头跳过去的选区只是为了指给作者看；作者点回正文、或按 Esc 回到正文，浮条照常出来。
- **给不该变身份的元素一个 key**：窗口的主体那一行 `body`、页面那一列 `page`（`shell.go`），正文那一块 `prose`（`chapterView`，上面的查找条、AI 条、提示条会来去）。key 只在父元素里唯一，所以沿着正文往上、兄弟会来去的每一层都要有：标题栏来去影响 `body`，侧栏来去影响 `page`，标签条、提示条、查找条来去影响 `prose`。

- **深色另有一个遮罩**：`tokens.css` 的 `.dark` 里 `--scrim: rgba(0,0,0,.55)`（.55 是透明度刻度里的一档）。代码照阴影的读法按块读（`scrims`），深色块里没写就用浅色那个。原型跟着变。`DESIGN.md` 里那一条写明，标「待作者确认」。

## Alternatives considered

- **F11 和藏侧栏的地方各自记下正文有没有焦点，切完再 `Focus()` 一次。** 最强的理由是改得最少、不碰布局。不用：要记得在每个会让布局变的地方都补一句（专注模式有快捷键、按钮、菜单三个入口，侧栏另有两个），漏一处就又丢；key 让元素本来就是同一个，以后加新的来去的东西也不用管。
- **在编辑器里处理 Esc 取消选中**（`editor/input.go` 里 Esc 现在只收续写建议）。理由是编辑器自己最清楚有没有选区。不用：原型的顺序是先关查找条再取消选中，编辑器不知道查找条开着没有；放在编辑器里，焦点在正文、查找条开着时第一下 Esc 会先取消选中。

- **深色的对话框底调亮一点，不加遮罩。** 理由是只动一个颜色。不用：遮罩的用处是告诉作者后面的页面现在点不了，只靠对话框和页面的明暗差说不清；而且 `raised` 还用在卡片、菜单上，调它牵连的地方多。

## Consequences

**收益**

- Esc、专注模式和原型对上了；进出专注模式、藏侧栏时可以接着打字。
- 关查找条只有一种写法，开始 AI 改写、起草、记伏笔以后正文里不再留着查找的高亮。

**代价与已知上限**

- key 只加在正文这条路上。别处（讨论页的输入框、设定的编辑框）如果上面有会来去的东西，同样会丢焦点；这次没逐个查。
- Esc 取消选中只在写作页、焦点在正文时；设定、讨论里的文本框照 mygo 自己的。
