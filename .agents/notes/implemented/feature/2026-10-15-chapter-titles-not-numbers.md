# Agent Note: 指某一章写它的标题，不另编「第 N 章」

Status: implemented

部分取代 [右栏](2026-10-10-right-pane.md) 里伏笔、设定出处的「第 N 章」，[一致性检查](2026-10-10-consistency-check.md) 和 [审查后的一批修正](../bug-fix/2026-10-14-review-fixes.md) 里检查页、页脚的「第 N 章」；[窗口走查的修正](../bug-fix/2026-10-14-window-walkthrough-fixes.md) 里「删没有设定的分类时写『这个分类下没有设定』」那条改成直接删。同一批（2026-10-15 作者过的原型第 1–6 项）还有回答 AI 的提问，见[回答 AI 的提问](2026-10-15-answering-the-ais-questions.md)。

## Problem

伏笔、检查、设定出处、页脚说到某一章，写的是按位置数出来的号：`chapterNo` 数章节树里第几个，`chapterLabel` 拼成「第4章」。作者自己的标题也常是「第四章 钟表铺」，两个号会对不上：

- 删一章、插一章、挪一章，位置号全变，作者写在标题里的号不变。「第 5 章埋下」指的可能是标题叫「第四章」的那一章。
- 卷外的序章、番外也被数进去。
- 伏笔选择器在第 3 章里也列出第 10 章才埋下的伏笔，「N 章前」从全书最后一章往前数，在前面的章回收时数字不对。

另外几处文案说的地方界面上没有：「模型设置」「在设置中提高预算」，设置里那一栏叫「AI」。

## Decision

规则写在 `DESIGN.md` 的「Do's and Don'ts」（指某一章写标题、正开着的写「本章」；文案里的地方和界面一字不差，指 AI 那一栏一律写「设置中「AI」配置」）。代码照它：

- **标题替代位置号**：`chapterLabel`、`chapterNo` 删掉。检查页的列表、详情（「正文 · 标题 · 第 N 段」）、「其他章节的类似情况」、「正在检查「X」」「已检查至「X」」「「X」检查失败」、待处理清单，用 `checkItem.title` 和 `checkAt`（同时给位置和标题，「已检查至」要按位置取最后一章）。设定出处用 `chapterTitle`。页脚一律「本章」。伏笔列表右边、详情「埋在「X」」「回收在「X」，相隔 N 章」「「X」里的原句已删除」、选回收时右栏「「X」里已有一处回收」。句子里的标题加「」，单独摆着的（列表右边、选择器那一行）不加。
- **距离照旧按位置数**：「已过 N 章」「相隔 N 章」「N 章前」。这是在数隔了多少章，不是在给某一章起名。
- **伏笔选择器只列能在这一章回收的**：`candidates` 返回这一章和它前面埋下的（`f.ch <= here`），`meta(here)` 写「本章埋下」「本章 · 已回收」「X · 已回收」「X · N 章前埋下」，N 从回收的这一章往前数。已回收的仍列出（一个伏笔可以有几处回收），作者 2026-10-15 定的。
- **文案**：`writing.ErrNoModel` 和原型同一句「请在设置中「AI」配置里选择写作模型」；预算不够的几处说「在设置中「AI」配置里提高预算」（同日去掉作品预算后改说调大上下文上限，见[上下文上限配在模型上](../architecture/2026-10-15-model-limits-and-usage.md)）；讨论框模型菜单最后一行「AI 配置…」；`ai`、`model` 两包的报错同改。`TestCopySaysWhereTheModelsAre` 扫 `desk`、`ai`、`model`、`writing`、`discussion` 的源码。
- **同一批的另两处**：
  - 窄窗口（宽不到 1180、不在列章节）收成一列图标的侧栏，底下回收站图标在齿轮上面，原来收起后找不到回收站。
  - 删分类：有设定的才问「N 条设定将移到“其他”」，空的点了就删（`dropCategory`）。作者 2026-10-15：「空分类不用提示」。

## Alternatives considered

- **位置号换成标题里解析出来的号**（标题以「第N章」开头就取它）。最强的理由：「第 4 章」比「第四章 钟表铺」短，列表右边放得下，和作者的号一致。没有用：作者的标题不一定有号（「尾声」「番外：雪夜」），有号的写法也五花八门；解析不出来时还得退回位置号或标题，两套说法混着出现。标题是作者写的，一定对得上。
- **伏笔选择器列全部，只在后面埋的那几条上标灰**。最强的理由：作者能看到全书有哪些伏笔。没有用：后面才埋的东西在这一章不可能被回收，列出来只会选错；要看全部，右栏伏笔列表里有。

## Consequences

**收益**

- 增删挪章以后，说到的那一章和目录里的标题一个字不差。
- 选回收时的数字是从这一章算的，和右栏「已过 N 章」不会互相打架（右栏是从全书最后一章算，说的是这个伏笔晾了多久）。

**代价与已知上限**

- 标题长时列表右边和名字一起缩，两边都截断（`paneRow` 的 side、原型 `.item .side`）；检查页「已检查至「X」」也截断。
- 检查结果里没有存位置，删掉的章在检查页写「已删除的章」。
- 「本章」只在正文页开着那一章时用；检查页、待处理清单里那一章照样写标题，待处理的行后面另加「 · 本章」。

## Verification

- `TestCheckAChapterAndSettleWhatItFinds`、`TestCheckOnlyWhenAsked`、`TestAChapterReadInPartIsToldSo`：页脚「本章尚未检查」「本章检查完成，有 3 处待处理」「本章仅检查前 N 字」；检查页「已检查至「第一章」」。不改时失败。
- `TestForeshadowBuryAndPay`：选择器「第一章 · 1 章前埋下」，详情「回收在「停电」，相隔 1 章」「埋在「第一章」」。`TestThePickerListsWhatCameBefore`：在第一章选回收，第二章埋下的不在里面、没有可选的；到第二章，它在，写「本章埋下」。去掉 `f.ch > here` 时失败。
- `TestSettingListAndPage`：出处「「第一章」“小祥把左手揣回兜里。”」。
- `TestCopySaysWhereTheModelsAre`：源码里没有「模型设置」「设置的「AI」」「在设置中提高」，`ErrNoModel` 是原型那一句。
- `TestASlimSidebarKeepsTheTrash`：1100 宽、讨论页，侧栏没有作品名，点「回收站」打开回收站。
- `TestCategoriesCountWhatIsKept`：删「地点」（没有设定）不问，直接出「已删除分类“地点”」。
- `npm run verify-prototype`：伏笔、检查、设定出处、「no model to write with」、「a narrow window」、空分类几步。
