# Agent Note: 右栏三个标签改成"一列 → 点一行看详情"

Status: implemented

> 2026-10-24 起原型里改了这一处，见[页边批注这一版界面](../../proposed/feature/2026-10-24-margin-notes.md)；软件跟上之前，本篇说的仍是软件现在的样子。

## Problem

正文页右栏的三个标签（设定、讨论、伏笔）各长各的，作者试用后的评价是"没有分级，整个都是一面，一堆文字，很拥挤，不知道如何操作"。问下来具体是三件事：

- **不知道点哪里**：设定的操作是悬停才出现的五个图标；伏笔详情底部并排四五个按钮。
- **看不懂是什么**："悬而未决""整理历史""其他未回收""挂到选中的句子上"都是软件自己的说法。
- **找不到想要的**：设定是整段文字从上排到下，没有搜索；一个人物有几条就散在几处。

作者在右栏里最常做的三件事是：查一个人或物、处理 AI 的建议、自己记一条。

设计稿前三轮（把设定做成一份文档、左名字右内容的双栏、加宽到 560）都被否了：前者"不直观"，后两者"占据太多空间"。作者选中的是 390 宽的窄列表、点一行看详情，定稿在设计稿 `SettingPane.dc.html`（「右栏：设定、伏笔、讨论」）。

## Decision

三个标签用同一个形状，只有两层，部件在 `desk/pane.go`：

- **一列**：最上面一行是搜索框（`paneFind`），只管找；它右边是「＋ 新增 / 新讨论」按钮；再右边「···」是一个菜单，放不常看的东西。下面一行一条（`paneRow`）：名字、一句内容、右边的章数或日期、箭头；小号浅字的分组名（`paneGroup`）。等作者处理的排在第一行，带一个琥珀色圆点和条数（`paneTodo`）。
- **点一行看这一条**：最上面一行左边是「‹ 全部…」回到列表，右边是对这一条做的事（删除设定、放弃伏笔、取消回收、删除伏笔），浅色文字（`paneBack`）。页面里只有一个实心按钮，在右下，次要的按钮在它左边（`paneButton`、`paneButtons`）。页面底部不放操作。
- 标签上的数字都是"等你处理的有几条"：设定是 AI 建议的条数，伏笔是原句已删的条数。

### 设定（`desk/setting.go`）

- 列表按分类列正文里的条目。有名字的条目显示"名字 + 一句内容"，没有名字的整行是内容。搜索查名字和内容，标题换成"找到 N 条"，找到的字加深；内容太长时从找到的字前面一点开始显示。
- 「等你决定」是 `open` 位置的条目，也就是 AI 提的、作者还没表态的。点进去每条下面是「忽略」（移到 `dropped`）和「采纳」（移到正文）。一条建议"关于谁"是算出来的（`App.ideas`）：和正文某条共用一个名字，或者内容里提到了它的名字，取最长的那个；都没有就是"新设定"。有建议的条目在列表里带圆点，它的详情页下面有「AI 建议」一段。
- 详情：名字、别名、全文、出处（"「章标题」“原句”"和「看原文」，2026-10-15 起写标题，见[指某一章写它的标题](2026-10-15-chapter-titles-not-numbers.md)）、「修改」。右上角「删除设定」把它移到 `dropped`。
- 修改和新增是同一个表单（`entryForm`）：名字、别名、内容、分类。新增时内容在最前，名字写"选填"。名字和别名分成两格，存的时候合成 `Names`（第一个是名字）。**任何分类都可以写名字**，以前只有人物、地点等五类显示名字一格。
- 「···」里是「已删除」（`dropped` 的条目，点开一条后右上角是「恢复设定」）和「修改记录」（原来的整理历史，内容没变）。栏顶的时钟图标去掉了；后台整理的小圆点还在，点它仍然打开修改记录。

### 伏笔（`desk/foreshadow.go`）

- 列表只列还没回收的：「原句已删」一行（只有一条时直接打开它，多条时进一个列表）、「久未回收」、「未回收」。一行是备注和章标题或"本章"（2026-10-15 前是"第 N 章"）。「已回收」「已放弃」在「···」里，各是一个列表。
- 去掉了：三个状态的筛选按钮、排序、每行下面的原句和"N 章前埋下"、详情里的「再加一处回收」和日期。一个伏笔仍然可以有几处回收（在正文里右键「记为回收…」再选它），只是详情页不再有这个按钮。
- 详情：备注和「改备注」；"埋在「章标题」，已过 M 章"和「看原文」；原句。下面按状态只有一件事：未回收是"先在正文选中回收的段落"和「记为回收」；原句已删是"先在正文选中新的句子"和「换个原句」；已回收列出每处"回收在「章标题」，相隔 M 章"和原文。右上角依次是「放弃伏笔」「取消回收」「删除伏笔」「恢复伏笔」（已放弃的）。
- 「删除伏笔」只对原句已删的出现，把这个标记整个删掉；以前这里是"不要这个伏笔"，做的是放弃。
- 正文右键菜单改了两项：「这里回收了伏笔…」→「记为回收…」，「查看这条伏笔」→「查看伏笔」。

### 讨论（`desk/beside.go`、`desk/chat.go`）

- 打开标签看到的还是当前这次讨论。最上面「‹ 全部讨论」去列表（`a.doc.talks`）：搜索标题、「新讨论」、按时间从新到旧，右边是"今天""昨天"或月日。原来的下拉菜单和栏顶的加号去掉了。
- 空的讨论不再有图标、标题和一段说明，改成"试试这样问"下面三行，点一行填进输入框。
- 输入框一行起，发送按钮在同一行；勾选框「附上本章内容」和模型在框下面一行。提示是"输入消息"，空讨论时是"想聊什么"。讨论页（不在右栏）的输入框没有变。

### 用词

按"一眼看懂、日常说法、名称 2–4 字"改的：悬而未决 → 等你决定；已放弃（设定）→ 已删除；整理历史 → 修改记录；原句被删 → 原句已删；埋了 N 章以上 → 久未回收；挂到选中的句子上 → 换个原句；在选中处回收 → 记为回收；附上本章 → 附上本章内容。磁盘上的 `open`、`dropped` 和给模型看的提示词没有改。

2026-10-14 起 AI 可以整个关掉（见[可以整个关掉 AI](2026-10-14-disable-ai.md)）：关着时右栏的标签只有「设定」「伏笔」，「设定」上不数「待确认」。

## Alternatives considered

- **设定就是一份文档，点哪句改哪句，AI 建议是跟在后面的一句灰字**（设计稿第二轮 2c） — 没有按钮和卡片，最像作者自己记的笔记，改一句不用进表单。作者试看后说"不直观，不便捷"：没有任何东西看起来能点，采纳和忽略是两个带下划线的词；条目多了以后还是一整面文字，找一个人要从头读。
- **左边名字、右边内容的双栏，栏加宽到 560**（第三轮 D1、D2） — 查人最快，点名字右边就换，不用来回进出。作者否了："占据太多空间"，正文页的稿纸被挤窄。现在的做法多一次点击，换来右栏保持 390。
- **搜索框兼新增：打字是找，找不到按回车就是记下一条**（第三轮 D3 原样） — 少一个按钮，记一条最快。作者要求拆开："搜索和新增混在一起了感觉不太好"。一个框两种结果，按回车前不知道会发生什么。
- **删除、放弃这类操作放在页面左下角的浅字** — 离主要按钮远，不容易误点。作者审稿时差点漏看，并指出"这些本质上也属于功能操作，这种一般是在右上角的"。
- **「已删除」「修改记录」「已回收」「已放弃」作为列表底部的几行** — 不用点开菜单就看得见。作者对这一块不满意：它们和上面的条目长得一样却不是条目，列表短的时候悬在半空，长的时候要滚到底。收进「···」后列表里只有条目。
- **「···」做成设计稿里画的自绘浮层** — 和设计稿一模一样，能显示右对齐的灰色条数。当时用的是系统菜单（`Element.Menu`）：软件里其他菜单都是系统菜单，键盘和读屏是现成的；条数写在名字后面（"已删除  3"）。2026-10-12 作者要菜单和原型一个样子，全软件的菜单都改成自己画的，条数回到右边，见[自己画的菜单](2026-10-12-own-menus.md)。
- **建议"关于谁"由后台整理时写进条目** — 比按名字猜准，不会把只是提到某人的建议算到他头上。这要改记账的输出格式和提示词，旧数据里也没有这个字段；先按名字算，算不出来的归"新设定"，不会丢。

## Consequences

- **收益**：三个标签学一次就会；每页只有一个主要按钮；设定能搜；AI 的建议集中在一处、一条一下；右栏里不再有悬停才出现的操作。
- **代价**：
  - 看一条设定的全文要多点一次；以前整面文字虽然乱，但不用点。
  - 设定列表不再显示 `open` 和 `dropped` 的条目，搜索也只搜正文里的；要找被删的得进「已删除」。
  - 建议"关于谁"是按名字猜的：内容里提到两个人时算到名字长的那个头上，可能不对。
  - 一条建议太长时「等你决定」一屏放不了几条；AI 写出的建议现在没有长度限制（2026-10-15 起由讨论当场记下，见[讨论用工具查全书、当场记设定](2026-10-15-talk-looks-up-and-notes-the-setting.md)）。
  - 伏笔的"最近埋下的在前"排序没有了。
  - 右栏的空讨论不再解释"勾着时正在写的内容会一起发过去"，只剩勾选框上的悬停说明。
- **和设计稿的差别**：「···」当时是系统菜单（现在不是了，见上）；空讨论的三行起头在上面，设计稿画在输入框上方；「已删除」的列表、「修改记录」页、已放弃伏笔的详情设计稿没有画，照同一个形状做的。
