# Agent Note: 设置「外观」里的「禁用 GPU 加速」，改了从下次打开起生效，可以立即重新打开

Status: implemented

## Problem

[作者看完重组以后](../bug-fix/2026-10-24-after-reviewing-the-reorganization.md)量出来：在作者的机器上（GeForce GT 610），mygo 用 GPU 画的每一帧都要等两次屏幕刷新，滚动最多每秒 30 帧；在内存里画（`MYGO_GPU=0`）一帧只要 2–4 ms。作者 2026-10-24 用 `MYGO_GPU=0` 打开试过：「确实顺手多了，可以考虑整个设置「禁用GPU加速」针对电脑配置不好的用户」。

环境变量只有会开终端的人用得上。mygo 在窗口画第一帧时看一次 `MYGO_GPU`（`ui/window.go` 的 `makeGPU`），开着的窗口中途换不了画法。

## Decision

- **设置「外观」最下面一个勾选框「禁用 GPU 加速」**，默认不勾。和「颜色」「正文中标出设定的名字」一样只管本机，存在 `works.json` 的 `noGPU`，不勾时不写。名字、位置和要不要「立即重新打开」都是作者定的；作者也说不要另加一句说明。
- **从下次打开起生效**：`desk.New` 读完书架，记下这次打开时的值（`ranNoGPU`）。`cmd/inkgo` 在窗口出现之前问 `d.NoGPU()`，是就设 `MYGO_GPU=0`。
- **勾的和这次打开时不一样，下面说「重新打开软件后生效。」，后面跟着文字按钮「立即重新打开」**（`kit.TickNoteLink`）。勾回去，这一句就没了。点了先关掉设置，再调 `cmd/inkgo` 给的 `Relaunch`，也就是 mygo 的 `App.Relaunch`：软件关掉，用同样的参数再打开，回到同一本书。有 AI 提议没处理时，先问「还有 N 处 AI 提议没有处理」，和关窗口时问的一样；「丢弃并关闭」以后才重新打开，「取消」就留在原处。
- **作品在重新打开之前关好**：`cmd/inkgo` 把 `d.Close()` 从 `main` 末尾的 `defer` 挪到 `mygo.App.OnQuit`。mygo 先调 `OnQuit` 再启动新进程（`app.go` 的 `finish`），所以存盘、关闭时的备份都做完了，新进程才打开同一本书，两个进程不会同时写它。平常关窗口，时机和原来一样都在窗口关掉以后。系统关机时 mygo 也调 `OnQuit`，原来的 `defer` 赶不上。
- 原型同改（`prototype/dialogs.js` 的 `gpuSwitch`），`walk.ts` 点一遍：勾上说要重新打开，勾回去不说，点「立即重新打开」关掉设置、按新的值画。

## Alternatives considered

- **软件自己判断，GPU 慢就自动改到内存里画** — 最强的理由：配置差的电脑上，大多数作者不会去设置里找这一项，自动判断不用他们知道什么是 GPU。这次不做：要在启动后量几秒交帧，判断「慢」的线怎么划、要不要先问作者，都还没有依据。只有作者一台机器的数，也没量过大窗口、高分屏在内存里画要花多少。作者说以后觉得有必要再加。
- **默认就在内存里画** — 最强的理由：在作者的机器上明显顺手。不用：在内存里画不跟屏幕刷新同步，GPU 正常的电脑上也会多占 CPU，而且只有一台机器的数。
- **改了马上生效，不用重新打开** — 最强的理由：别的设置都是马上生效的。做不到：mygo 只在窗口画第一帧时决定画法，开着的窗口换不了，只能关掉窗口再开一个。所以给了「立即重新打开」，一下就好。

## Consequences

- **收益**：配置差的电脑上，作者在设置里勾一下、点一下就能换成在内存里画，不用开终端设环境变量。
- **同一天关掉了**：mygo 不用 GPU 画时，在 Windows 上贴不上大多数的帧，窗口是白的，勾上的人连这一项都看不见。这一项先不给（`offerNoGPU`），上游修好再放出来，见[白窗口那篇](../bug-fix/2026-10-24-no-gpu-white-window.md)。下面说的做法都还在，只是关着。
- **代价与已知上限**：
  - 依赖 mygo 的 `MYGO_GPU` 环境变量和它「画第一帧时看一次」的做法。mygo 哪天改了这个变量的名字或时机，这一项就会悄悄失效，升级 mygo 时要查。
  - 旧版软件读到带 `noGPU` 的 `works.json` 会因为不认识的字段报错，和以前加 `theme`、`noNames` 一样，不能再退回旧版。
  - 在终端里另设了 `MYGO_GPU` 打开的，设置里显示的是书架里存的值，不是这次实际的画法。

## Verification

- `desk/settings_test.go` 的 `TestNoGPUWaitsForTheNextStart`：
  - 勾上以后，说要重新打开；没有 `Relaunch` 时不出按钮；下一个 `App` 读到的是勾上；勾回去以后不再说。
  - 有 AI 提议时，点「立即重新打开」先问；「丢弃并关闭」以后才调 `Relaunch`，而且只调一次。
- `shelf/shelf_test.go` 的 `TestShelfNoGPU`：不勾时不写，勾上存成 `"noGPU": true`，能读回来。
- `npm run verify-prototype` 的「the look, reminders and backups」那一步。
