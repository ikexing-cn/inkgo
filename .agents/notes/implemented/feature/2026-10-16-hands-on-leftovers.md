# Agent Note: 真机走查里看到、和作者过了以后才改的几处

Status: implemented

## Problem

2026-10-16 在真窗口里走了一遍（改了的见[又一次真机走查的修正](2026-10-16-hands-on-pass.md)），下面几处看到了没改：有的要先和作者定说法，有的要先在原型里做出来。作者说晚点一起过，先记在这里。

1. **没选文字时「记为回收」「更换原句」照样能按**：右栏伏笔详情里，未回收的写着"请先在正文中选中回收的段落"，下面的「记为回收」是黑的；按下去弹一条提示"请先在正文中选中回收伏笔的段落"，把右栏那句又说一遍。失去锚点的「更换原句」同样（"请先在正文中选中要关联的句子"）。右键菜单里的「记为回收…」没选文字时是灰的，两处不一样。`DESIGN.md` Components 的「表单」说"不等作者按了才弹提示条说不行"，可同一节的「提示条」正拿"请先在正文中选中回收伏笔的段落"当不带图标的例子，原型走查的「pay off with nothing picked」也查它。
2. **「回答」把问题原有的名字丢掉**：右栏待确认里，AI 问的一条（以问号结尾）点「回答」，表单的名字、别名两栏是空的（`desk/setting.go` 的 `idea` 里 `d.name, d.names = "", ""`）。`workspace` 的 `OpAnswer` 把条目的 `Names` 换成表单填的，所以问题条目原来带着名字、作者没再填一遍时，存下的答案没有名字，原来的名字也没了。没有名字的条目在列表和发给 AI 的设定里只能用第一句的开头指它。
3. **有章检查失败时，检查页上面仍写「已检查至「某章」」**：标题已是"检查未完成"、带警告（c614831），工具条那一行还按查到最后的一章写"已检查至"，读着像那一章以前都查过了。
4. **新建作品的位置框只露出路径的开头**：路径长时文件夹名在后面被截掉，正是作者要核对的那段。常见长度放得下。
5. **作品分类点「编辑」以后没有「取消」**：表单一直在页面底下，填进去的只能自己清掉两栏。留着不会出事，按保存也只是原样再存一遍。服务表单新加了「取消」（09d7864），这里没有。
6. **别的就地展开的表单会不会也开在视野外**：服务表单原来开在列表最下面看不见的地方，现在打开时滚进视野。右栏新增设定、回答、伏笔备注这些就地表单没有逐个查过。

## Decision

2026-10-19 作者说「按你推荐的来」，六条照下面做了，先在原型里改，再改程序。

1. **没选文字时两个按钮是灰的**：右栏伏笔详情的「记为回收」「更换原句」，正文里没选文字、或正文只读时灰着，点了什么也不发生，和右键菜单的「记为回收…」一样（`desk/foreshadow.go` 的 `unpicked`，原型看 `S.bar`）。上面那句「请先在正文中选中……」一直在，不随选区变，免得作者拖选时右栏跳动。`openPay`、`rehang` 里的提示留着兜底。`DESIGN.md` 的「表单」加了这一条；「提示条」不带图标的例子只剩「各章均已检查，正文无新改动」，走查改在「the whole book checked」那一步查它。
2. **「回答」带着问题的名字**：第一个进名字栏，其余进别名栏；作者删了才算不要。原型假书里那个问题带上了「林晚」。
3. **有章检查失败时那一行写「已检查 N 章，M 章失败」**：N 是查过、最后一次没失败的章，M 是最后一次失败的章，都只算还在书里的。没有失败的照旧写「已检查至「某章」」。
4. **位置下面的说明写出文件夹名**：「将新建文件夹「新书」。」「文件夹「空文件夹」为空，作品将建在其中。」「文件夹「旧稿」中已有文件，请更换名称或位置。」，是文件、打不开的也这样写。框里照旧从头显示路径。
5. **作品分类的表单里是已有分类时有「取消」**：在「保存分类」左边，清空两栏，分类不变；填的是新名字时没有它。
6. **就地表单**：右栏的新增设定、回答、修改设定、记一处变化都是整页换成表单，修改伏笔备注就在点的那一行展开，打开时都在视野里，不用改。作品分类的表单在列表下面，分类多了点上面一行的「编辑」会看不到，照服务表单的做法，点「编辑」的那一帧把表单滚进视野（`categoryShow`）。
