# Agent Note: 备份：整部作品定时打成 zip，复制到别处

Status: implemented

## Problem

作品只存在这台电脑上。快照（`history/`）只能防改错，硬盘坏了、电脑丢了，快照会跟着一起没。设计稿「备份」页（1a）定下的做法：
- 第一次打开作品时问一句备份到哪；
- 平时侧栏底部只有一行小字；
- 失败时窗口右上角出一行琥珀色提示；
- 在设置页里管。

2026-10-09 作者定了三件设计稿没说的事：
- 齿轮进「设置」页，左边分栏；
- 每次备份存成一个 zip；
- 备份设置记在这台电脑上。

## Decision

- **备份内容**：作品文件夹里除 `.writer/` 以外的全部文件（正文、章纲、设定、对话、快照、`work.yaml`）。`.writer/` 是本机的界面状态和日志，不带。
- **格式**：每次一个 zip，文件名「作品名 2026-10-09 10.32.00.zip」。时间不用冒号，Windows 不认。作品名里文件名不能有的字符换成 `_`。
  - zip 的注释里写一段 JSON：作品 ID、文件摘要、字数、章数（`backup.Meta`）。
  - 列备份时按注释里的作品 ID 认，不按文件名。作品改名后仍认得旧备份；几部作品可以备份到同一个文件夹。
  - 和最新一份的摘要相同就不再写，不会因为「每天一次」攒出一串一样的备份。
- **怎么写**（`backup` 包）：
  - 先在作品的锁里读出全部文件（`Store.Hold` + `backup.Read`），保证读到的是同一时刻的作品；读文件很快，写作时察觉不到。
  - 再在后台写 zip：先写临时文件，写完改名。移动硬盘慢也不卡界面，中途拔掉也不留下半个 zip。
  - 写完按「留几份」删掉最旧的。
  - 备份文件夹不在（移动硬盘没插）时直接报错，不替作者新建。否则新插的别的盘占了同一个盘符，会把备份写到那上面。
- **什么时候备份**：三项可以同时选，默认前两项。
  - **关闭作品时**：切换作品、回到作品列表、关窗口时，等备份写完再关。
  - **每天一次**：当天还没备份过就备份；没改过的话摘要相同，不会多出一份。
  - **写作时每小时一次**：在正文页、离上次成功满一小时。
  - 每分钟最多检查一次是否该备份。失败后 10 分钟内不自动重试，作者可以随时点「重试」。
- **设置存放**：存在本机的作品清单 `works.json` 里，每部作品一份 `backup` 字段：
  - 文件夹、三个时机、留几份（默认 30）；
  - 上次成功的时间；
  - 「以后再说」的时间、「今天不提醒」的日期。
  `shelf.Put` 更新作品信息时保留这一项。
- **界面**：
  - **第一次打开作品**：对话框问备份到哪（设计稿 A1）。
    - 找得到的同步文件夹列在前面，备份到里面的「写作备份」文件夹：OneDrive（看 `%OneDrive%`）、坚果云（`~/Nutstore/*/我的坚果云`）、Dropbox、iCloud 云盘。
    - 最后一项是「自己选一个文件夹…」。
    - 「什么时候备份」是一个下拉菜单，三项可以勾选。
    - 选「以后再说」，一周后打开这部作品时再问。
    - 只有 `App.Backups` 打开时才问。`cmd/poc` 打开它；测试里默认不问，免得对话框挡住别的测试。
  - **侧栏底部**（A2）：一行「已备份 · 今天 10:32」。
    - 点开是卡片：备份在哪、下次什么时候、「立即备份」「备份设置…」。
    - 失败时这一行变成「备份没成功」，用正文色。
  - **失败时**（A3）：
    - 正文工具栏右边出现琥珀色的「备份没成功 · 找不到 E 盘」。
    - 点开是原因和三个按钮：重试、换个地方、今天不提醒。
    - 原因分四种：盘符不在（「移动硬盘可能没插」）、文件夹不在、没有写权限、其他（直接给出错误）。
    - 「今天不提醒」只收起工具栏那一条，侧栏那一行照旧。
  - **待处理**里有「备份」一组，照待处理设计稿：一条「备份没成功，找不到 E 盘」，副标题「点一下重试 · 上次备份 …」，点一下就重试。忽略后，到下一次备份成功之前不再列出。
  - **设置**：侧栏底部回收站旁边是齿轮。作者 2026-10-09 在设计稿「设置页布局」里选了 A1：设置是盖在当前页面上的弹窗（`a.bk.prefs`），关掉回到原处。弹窗固定 880×660（窗口小时缩到四边各留 20），哪一项都不变大小——作者不要弹窗随内容变矮。左栏「模型」「外观」「备份」，默认「模型」；出错和提示显示在弹窗内容顶上，因为页面上的横幅被弹窗盖住。
    - 模型：作者要求把原来侧栏导航里的「模型设置」页并进来，侧栏导航不再有这一项（设计稿的侧栏组件和导入稿件页已同步）。按 A1 排成三块：「这部作品用」讨论、整理、写作三行一张表，下面是上下文预算和「保存」；「写作时」两个勾选；「模型服务」列出本机保存的服务，「编辑」在这一行下面展开表单（`a.bk.edit`），「添加服务」同样在列表末尾展开。旧的 `a.page = 1`、`4`（讨论框里的「模型设置…」、截图测试）进来时打开弹窗，页面留在原处。
    - 外观：和「视图」菜单里一样的三选一，排成一行「颜色」。
    - 备份：
      - 状态卡：最近一次、字数章数、共保留几份、最早一份的日期，加上「立即备份」；
      - 备份到（换一个）；
      - 什么时候备份（三个勾选）；
      - 留几份（10/30/90，2026-10-12 照原型改的；原来是 10/30/60/100，以前存下的 60、100 仍在下拉里），旁边写每份多大、一共占多少。
      - 改小「留几份」不马上删，下次备份时再删。
  - 侧栏顶部的「‹ ›」和底部的「回收站」原来只在正文页出现，其他页那两处是空的。作者指出太空，按设计稿改成每一页都有：在别的页点「‹」会回到正文页，再退到上一章（`writeView.stepTo`）；回收站对话框也改成在每一页都能打开。

## Alternatives considered

- **每次复制整个文件夹** — 备份就是普通文件夹，不用本软件也能直接打开看，最直观。但留 30 份就是 30 个完整副本，文件多、占地方，往网盘同步也慢；一份 zip 好数、好删、写入时可以整份原子落盘。作者选了 zip。
- **设置记在作品文件夹里（`.writer/desk.json`）** — 换电脑时设置跟着走，不用再问。但「E 盘」「D:\Nutstore」这种路径只对这台电脑有意义，作品同步到另一台电脑上，那边没有 E 盘就会一直报失败。作者选了记在本机。
- **一页「提醒与检查」**（设置设计稿那一版） — 伏笔、一致性、备份的规则放在同一页，改一处就看到全部。但以后设置会越来越多，一长页不好找；备份设计稿 A4 的左侧分栏能装下外观、快捷键、关于。作者选了分栏。
- **设置是整页，左边再加一列灰色竖栏**（2026-10-09 先做的一版） — 和侧栏导航到别的页一样，不用新的交互。但侧栏旁边再加一列竖栏显得挤，模型服务占了整列；外观一项只有一行，整页大片空白。作者看了觉得难看。
- **侧栏换成设置目录**（设计稿 B） — 只剩一栏内容，外观、快捷键、关于合成「通用」，系统设置和 VS Code 都这样做。作者选了弹窗：写作时打开设置不离开正文。
- **一页长卷**（设计稿 C） — 内容少的项夹在中间不显空。但一页很长，要找某一项得滚或点目录。
- **弹窗高度跟着内容走**（设计稿 A2 第一版） — 外观只有一行时弹窗变矮，不留空白。作者不满意：切换左栏时弹窗跳动大小，固定宽高更稳。
- **放进现有的模型设置页** — 不加新页面，改动最小。但那一页讲模型和作品分类，备份放进去不好找，以后伏笔、一致性的设置也没处放。
- **按文件名里的作品名认备份** — 不用打开 zip 读注释，列得更快。但作品改名后会认不出旧备份，按「留几份」删旧备份时也会漏删；几部作品同名时还会互相删。读每个 zip 的注释只读文件末尾，几十份也很快。
- **失败只进待处理，不在工具栏提示** — 更安静，符合「写的时候不打扰」。但总览设计稿写明备份失败要在窗口右上角出一行琥珀色提示：硬盘没插的时候，作者最好马上知道。所以工具栏提示和待处理都有，「今天不提醒」可以收起工具栏那一条。

## Consequences

- **收益**：稿子有了这台电脑以外的副本；默认关闭时和每天各一次，作者不用记着手动备份；失败会说清原因和该怎么做。
- **代价**：
  - 关闭作品、切换作品、关窗口时要等备份写完；备份到慢盘或网络盘时会慢一点。
  - 旧版程序读到带 `backup` 字段的 `works.json` 会因为不认识的字段而报错，不能再退回旧版。
  - **恢复还没做**。设计稿 A5「从备份恢复」（选一份、看哪些章变了、只恢复一章或恢复整部）是下一步；在那之前，侧栏卡片和设置页都没有「从备份恢复…」按钮，要恢复只能手动解压 zip。`backup.Unpack` 已经写好并测过，恢复会用它把备份解到临时文件夹再比较。它按本机的路径规则看每个条目的名字：会落到目标文件夹外面的（`..`、盘符、Windows 上用反斜杠写的）和落在 `.writer` 里的都拒绝（2026-10-14 收紧：原来只按 `/` 看，`..\x` 在 Windows 上能写到外面）。
  - 「这部作品用」仍要点「保存」才生效，设计稿 A1 上没有画这个按钮：三项一起校验，选到一半（换了服务还没填模型）不能先存。
  - 设置还没有设计稿 A1 里的「快捷键」「关于」两项，作者 2026-10-09 说暂时不做；快捷键仍是侧栏作品菜单里的「快捷键…」对话框。
  - 同步文件夹按常见的默认位置找，装在别处的找不到，作者可以用「自己选一个文件夹…」。

## Testing

- `backup/backup_test.go`：
  - 不带 `.writer/`；内容没变时不再写；
  - 按作品 ID 列出，忽略别的 zip 和别的作品；改名后仍认得旧备份；
  - 只留最近几份；解开后内容一致；
  - 备份文件夹不在时报错、不新建。
- `shelf/shelf_test.go`：备份设置能存能读，`Put` 不会把它清掉。
- `desk/backup_test.go`：
  - 第一次打开时询问，「开始备份」后马上有一份，侧栏显示「已备份 · 今天 …」；
  - 再打开不再问；关闭作品时备份新改动。
  - 「以后再说」后再打开不问。
  - 失败时侧栏、工具栏、待处理都有；「今天不提醒」只收起工具栏那一条；文件夹回来后「重试」成功。
  - 设置弹窗显示份数和最早日期，勾选能存；外观一栏能打开。
