# Agent Note: 出错、进行中、成功都改成右上角的浮层提示

Status: implemented

## Problem

出错、进行中、成功原来都是页面顶上的一整条横条（`banners`）：

- 横条会把整页往下推。
- 设置弹窗开着时，同一条报错页面上一条、弹窗里又一条。弹窗里那条是为了不被遮罩挡住才加的。
- 红色底在深色模式下很刺眼。

作者 2026-10-09 看了截图说"这个提示很蛋疼"，要求换成一个新的弹出层组件，先出设计稿。设计稿「提示」页画了六种状态和两种位置，作者选了右上角（P1）。

## Decision

- 提示用 mygo v0.2.15 自带的 toast 底层（`ui.ToastViewportBase`、`ui.ToastBase`），外观照设计稿自己画（`desk/toast.go`）。
  - 计时、鼠标停在上面时暂停、同一个 ID 只显示一条、浮在所有弹窗上面，都由 mygo 负责。
  - 提示层在视图的最后建（`View` 末尾的 `a.toasts`），排在设置弹窗和其他对话框后面，所以盖在它们上面。
- `a.err`、`a.busy`、`a.notice` 保存提示的状态；错误只存一个 `error` 值，由 `SetError` 写入或清空，显示和复制取它的 `Error()`。
  - 每帧对照三个字段：有值且和上次显示的不同，就以固定 ID（`error`、`busy`、`notice`）加一条提示；字段清空了，就关掉对应的提示。
  - 提示被作者关掉或到时自己消失时，清掉对应的字段。这样测试和其他代码看到的字段含义不变。
- 位置：右上角，标题栏和各页顶栏下面 12px（离窗口上边 92）、离右边 16px，宽 360，新的在上。
  - 最多摆 2 条，更早的收成「还有 N 条」，点开全部显示。
- 样式：浮层底色加边框和阴影，圆角 10，只有图标带颜色。
  - 出错是三角形，用 `Danger` 色；成功是圆圈加勾，用 `Success` 色；进行中是转圈。
  - 文字在第一个「：」「；」「。」处分开，前半句当标题，后半句当说明（`splitToast`）。
- 各状态：
  - 出错：一直留着，直到点关闭。
    - 按钮是「重试」「打开设置」「复制详情」，靠右排，最要紧的「重试」在最右（2026-10-13 起，见[按钮靠右](../process/2026-10-13-buttons-at-the-right.md)；之前靠左，「重试」在最左）。
    - 「重试」只在报错来自后台请求（`run`）时出现，重新跑同一个请求（`a.again`）。
    - 「打开设置」在问题能通过设置修正时显示，由 AI 端以 `aiport.SetupError` 标记，`desk` 用 `errors.As` 判断。超时、限流、服务端错误和损坏的回复不提供此入口。标记由 `ai` 在端口处转换，下层使用 `model.SetupError`。
    - 「复制详情」把完整报错放进剪贴板。
  - 同一个请求连续以同一条报错失败时，不叠新的，而是在标题后计数「×2」（`a.failed`、`a.fails`）；请求成功一次就清零。
  - 进行中：带「取消」，按钮的标签仍叫「取消请求」，测试和读屏按这个名字找。正在讨论、而且讨论区在屏幕上时，不显示这条，因为讨论区自己显示进度。
  - 成功：3 秒后消失（`noticeFor`），底下一条 2px 的细线显示剩下的时间。
- 页面顶上、讨论页、正文页、设置弹窗里的横条全部删除（`banners`、`pageBanners`、`fresh`）。
- 设计稿里的「警告」「普通」两种状态，现在没有代码会发出，暂不接入；以后有地方要发再加。

## Alternatives considered

- **自己算位置和层级，不用 mygo 的 toast** — 外观和行为完全由自己控制。但 mygo 的 toast 已经处理了计时暂停、窗口失焦时暂停、Escape 关闭、读屏播报和层级，自己写要重做一遍。它只管行为不管外观，正好用来画设计稿的样子。
- **改各处代码直接调 `c.AddToast`，不再用 `a.err` 这些字段** — 来源和提示一一对应，也不用每帧对照。但要改二十多处，而且很多地方在后台结果回来时才设错误，那里拿不到 `ui.Context`；测试也都在检查这几个字段。
- **顶部居中（设计稿 P2）** — 更显眼。但它正好落在正文开头几行上，写的时候会挡字；作者选了右上角。
- **保留弹窗里那条横条，只改页面上的** — 改动小。但浮层本来就盖在弹窗上面，弹窗里再放一条就又重复了。

本篇取代 [2026-10-09-walkthrough-fixes](2026-10-09-walkthrough-fixes.md) 里「提示自动消失」的做法，以及它放弃 toast 的理由：当时 mygo 没有现成的浮层提示，v0.2.15 有了。

## Consequences

- **收益**：
  - 提示不再推动页面，弹窗开着时也只出现一次。
  - 深色模式下只有图标有颜色。
  - 报错能直接重试、去改模型设置或复制原文。
- **代价**：
  - 成功提示只留 3 秒，比原来的 8 秒短。长一点的句子分成了标题和说明，鼠标停在上面时不走。
  - 右栏开着时，提示宽 360、右栏 300，会盖住正文栏最右边约 76px。[2026-10-09-merged-title-bar](../../archived/feature/2026-10-09-merged-title-bar.md) 放弃浮层横条，就是因为它挡住了「磁盘上被改过」那条提示的按钮。现在报错一直留着，如果正好压在那里，要先关掉提示才点得到。
  - 成功提示显示的 3 秒里每帧都重画，用来画倒计时线。
