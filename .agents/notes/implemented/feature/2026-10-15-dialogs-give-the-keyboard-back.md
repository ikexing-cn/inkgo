# Agent Note: 对话框关掉，键盘回到打开它之前的地方

Status: implemented

## Problem

在真窗口里点的时候发现：正文里打着字，点左下角的齿轮打开设置，再关掉，接着打的字哪儿也不进，要再点一下正文。作者 2026-10-15 定了做成通用规则：「关掉对话框，键盘回到打开它之前所在的地方」，先写进 `DESIGN.md`，加检查。

逐个入口查了一遍（正文有光标 → 打开 → Esc 关掉 → 看焦点）：齿轮、侧栏的回收站、选区浮条的「加入设定」、提示里的「打开设置」都回不来。从标题栏菜单打开的对话框回得来，标题栏自己有一套还光标的办法（[标题栏](2026-10-13-title-bar-row.md)的 `barState`）。

原因有两种：

1. mygo 的按钮一按就拿走键盘。对话框关掉时 mygo 会把焦点还给「对话框出来那一刻有焦点的元素」，可那一刻焦点已经在被按的按钮上了，于是还给了齿轮。
2. 打开对话框的按钮跟着对话框一起不见了（选区浮条在对话框开着时收起），焦点要还的那个元素已经没了，就哪儿也不还。

## Decision

- **打开对话框的按钮按下时不拿走键盘**（`KeepFocus`）：侧栏的齿轮、侧栏的回收站、选区浮条上的按钮、提示条上的按钮、讨论里的「摘取原文」。这样对话框出来那一刻焦点还在正文（或者原来在的那个框里），关掉时 mygo 自己还回去，不用另记状态。
- 别的按钮不加：正在改的章名、设定这些靠「失去焦点就算改完」，点「新建章节」之类的按钮要照常拿走键盘，改的东西才会存下。
- 标题栏的菜单不改，照旧用 `barState`（理由见下面「考虑过的其他做法」）。
- 原型照着做：这些按钮带 `data-keep`，按下时不让浏览器挪焦点（和标题栏的 `mousedown` 同一处）；重画时看对话框是不是这一遍出来的，出来时记下焦点和选区，关掉时还回去。

## Alternatives considered

- **所有按钮都 `KeepFocus`**（写在 `iconButton`、`ghost` 这些公用的按钮里）。最强的理由：一处改完，以后新加的打开对话框的按钮自动对，不用记得加。没有用：正在改章名时点「新建章节」，改名框没有失去焦点，改了一半的章名就丢了（`TestARenameEndsAtAnotherButton` 就是查这个的，试过，失败）；设定表、伏笔备注这些「点别处就算改完」的地方都会跟着坏。
- **标题栏也改用 `KeepFocus`，删掉 `barState`**，全软件只剩一种办法。最强的理由：两套办法做同一件事，少一套少一份要懂的东西。试过，菜单那几条都不还了：菜单第一行是 `AutoFocus` 的，mygo 记「还给谁」是在建完浮层里面的东西之后（`ui/widgets.go` 的 `coreOverlay` 先 `fn()` 再 `openOverlay`），记下的是菜单第一行。这是 mygo 的毛病，等它改了再合成一套。
- **对话框关掉时一律把光标放回正文**。最强的理由：最简单，写作软件里多半是从正文出发的。没有用：从讨论的输入框、设定的搜索框出发的，关掉以后该回到那里，不该被拉进正文。

## Consequences

**收益**

- 从正文打开设置、回收站、快照、导出、快捷键、加入设定，关掉以后接着打字，光标在原处。
- 不另记状态：靠 mygo 本来就有的「关掉还给原来的元素」。

**代价与已知上限**

- 新加一个打开对话框的按钮，要记得 `KeepFocus`，不加的话 `TestDialogsGiveTheKeyboardBack` 只查已经列进去的那些入口，查不出新的。
- 用键盘 Tab 到齿轮再按回车打开的，关掉以后焦点回到齿轮上，不回正文：那时键盘本来就在齿轮上，和规则一致。
- 对话框里如果有 `AutoFocus` 的输入框，会踩到上面那个 mygo 的毛病，关掉以后焦点哪儿也不在。现在的对话框都没有；以后要加，得先绕开它。
- 标题栏和别的入口用的是两种办法，见上。

## Verification

- `TestDialogsGiveTheKeyboardBack`：正文有光标时，从齿轮、侧栏的回收站、「文件」菜单的设置/快照/导出、「帮助」的快捷键、选区浮条的「加入设定」、提示里的「打开设置」打开，按 Esc 或点「关闭」关掉，焦点回到正文。不改时 10 条全部失败（包括菜单那几条：连着跑时前面的残留状态让它们也失败）。
- `TestARenameEndsAtAnotherButton`：改章名时点「新建章节」，章名存下了。所有按钮都 `KeepFocus` 时失败。
- `npm run verify-prototype` 的「the title bar, and the sidebar put away on every page」：光标放在第一段第 2 个字后面，点齿轮、点回收站，各按 Esc 关掉，光标还在正文的原处。原型不改时失败。
