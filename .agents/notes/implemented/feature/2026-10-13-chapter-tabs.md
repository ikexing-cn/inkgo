# Agent Note: 正文多标签页，保存状态改成标签上的圆点

Status: implemented

## Problem

作者 2026-10-13 看软件时说了两件事：

- 「我发现个很大的问题，我们没有多标签页」。一次只开一章：写第 87 章时想对照第 84 章，点过去，第 87 章就被换掉了，只能靠 ‹ › 来回。
- 顶栏章节名后面那句「已保存」，「这个形式我不太喜欢」。没有说想要什么样的。

先在原型里做了给作者看（`AGENTS.md` 界面那节第 2 条），几轮意见都落在原型里：标签要自己占一行（「标识性不够强，每个标签页之间没有切割，标签页和功能按钮拥挤而且都位于 header」）；点章节是新开；「点目录不应该打开标签页，目录只负责左侧的管理」；关掉有没存的字的标签页要先问（「存在编辑状态的情况下，点击取消居然没有问要不要保存？」）；问的对话框「不要扁着的」；三个按钮照系统的先后。之后作者两次说「同步原型设计到软件」「继续」，这一篇记的是照原型写进软件的样子。

## Decision

样子、文案、交互都照原型（`prototype/write.js` 的 `go`、`shutTabs`、`sheets`，`prototype/dialogs.js` 的 `unsavedDialog`，样式 `.sheets`、`.sheet`），规则在 `DESIGN.md` 的「标签页和保存」。软件里在 `desk/tabs.go`：

- **一行标签页**，在工具栏下面，高 32，侧栏那种浅灰底。一格一个，是一章或一卷的卷纲：图标、名字、关闭的叉；格子之间一条竖线，行底下一条线一直到右边。正看的那格是正文的底色、字加粗，底下的线到它那里断开。名字最宽 200，再长截断；排不下时整排左右滚，正看的那个总在看得见的地方。专注写作、一个标签页都没有时这一行不在。
- **打开**（`openNode`）：已经有它的标签页就切过去，没有就在正看的那个右边开一个。章节树、「查看原文」、‹ ›、Ctrl+PgUp/PgDn、新建章节走的都是它。切走之前照原来换章的做法先存，不问。
- **每个标签页留着自己的编辑器**（`writeView.parked`，一章一个 `sheet`）：切走时把编辑器和「存到哪一版、盘上的时间戳、上次快照的时间、外面改过还没选、盘上找不到了」一起收着，切回来原样放回，撤销记录、光标、滚到哪都还在。切回来时读一遍盘：盘上的字和标记跟收着的一样，就接着用；不一样（全书替换、伏笔改了别的章的标记、软件外面改了），丢掉收着的重新读，和以前换章一样。收着的那份还有没存上的字、或者是盘上找不到的章，就不读盘，原样放回。
- **章节树里点卷只折起、展开**。卷纲那一页从卷的右键菜单第一项「编辑卷纲」打开，这时才有它的标签页。在卷上右键「新建章节」「新建文件夹」直接建在这一卷的末尾（`newNodeAt`），不用先点开它。
- **关闭**（`shutTabs`）：标签上的叉（正看的那个一直有，别的指针移上去才显出来，位置一直留着）、Ctrl+W、标签上右键「关闭」「关闭其他」「关闭右侧」（没有可关的就是灰的）。关掉正看的，换到右边那个，没有就左边；一个不剩是空页「从左侧选择一章开始写作」，这时 ‹ 回到刚关掉的那一章。Ctrl+Tab、Ctrl+Shift+Tab 换到下一个、上一个，到头绕回去。
- **关掉的标签页里还有没存的字，先问**（`askToSave`）：窄的一档对话框（`dialogAsk` 360），「保存对「章名」的修改？」「不保存将丢失上次保存后的修改。」，按钮靠右，照系统的先后「保存」（主按钮）「不保存」「取消」。问着的时候不自动保存（`watch` 先看 `closing`）。「保存」存了再关；「不保存」这一章回到盘上的样子再关；「取消」和 Esc 什么都不动。没存的字指正文、章纲、摘要里任何一样，也包括两种盘上和这里不一样的章：软件外面改了、作者还没选留哪一版的（选「保存」是留这里的，盘上那一版存成快照）；盘上已经找不到的（选「保存」是存成新的一章，留在原来那个标签页里不关）。「关闭其他」「关闭右侧」里有几章要问，就一章一章问。
- **保存状态**：工具栏不再写「已保存」「未保存」。没存的那一章，标签上叉的位置是一个 6 的圆点，指针移到标签上换回叉；提示里写「卷名 › 章名 · 未保存」。Ctrl+S 的提示还在。
- **进回收站的章，标签页跟着关**（`trashNode`、`keepTabs`）：关的是正看的，换到它旁边的标签页；一个不剩，打开树里站在它原来位置上的那一章。
- **记在作品里**：开着哪几个（`tabs`）、正看哪个（`chapter`）、是不是全关了（`blank`），写进作品的界面偏好，下次打开还在。全关了以后回到正文页不会自己再打开第一章。
- 快捷键表「正文」一组加了 `Ctrl+Tab / Ctrl+Shift+Tab` 和 `Ctrl+W`。
- 同一次里顺手对齐原型的两处：菜单「导出…」在开着一章时先选「本章」（原来是「全书」）；右栏的两个按钮叫「收起右栏」「展开右栏」（原来在正文页叫「收起设定」「展开设定」）。

## Alternatives considered

- **点章节树仍在当前标签页里换章，要同时开着才「在新标签页打开」（Ctrl+点、中键、右键菜单），和浏览器、Obsidian 一样** — 随手翻章节不会攒出一排标签，不想用标签页的人什么都不用学。没有选：只点章节树永远只有一个标签，看上去和没有标签页一样，要先知道 Ctrl+点才用得上；作者定的是点章节新开。
- **VS Code 那样的预览标签：单击开的标签会被下一次单击替换，双击或在里面打了字才留住** — 两头都顾到，翻章节不攒标签，要留的又留得住。没有选：「这个标签是临时的」要用斜体之类的样子告诉人，中文斜体难看，规则也要解释一遍才懂。
- **标签放在顶栏里，替掉「卷名 › 章名」，做成圆角的小块** — 不多占一行，正文高度不变。这是原型的第一版，作者看了以后不要，让参考 VS Code。
- **「已保存」挪到底栏字数旁边** — 想确认存没存的人一直看得到。没有选：停笔片刻就自己存，绝大多数时候它写的都是「已保存」，一直占着地方；存不上时本来就有提示。
- **不留编辑器，切回来重新读盘，只记光标** — 最省事，也不占内存，以前换章就是这样。没有选：撤销记录和滚到哪就没了，两章之间来回对照正是开标签页要做的事，每次回来都从头找位置。
- **留着编辑器，切回来一律不读盘** — 少一次读盘，也不会「回来发现撤销记录没了」。没有选：全书替换、伏笔页会改没在看的那一章，软件外面也会改；不读盘，回来看到的是旧字，一打字就把盘上的新字盖掉。
- **三个按钮照别的对话框，主按钮「保存」放最右** — 全软件只有一条规则。没有选：作者拿记事本的那一排截了图要照它来；这是 `DESIGN.md` 写明的唯一例外。

## Consequences

**收益**

- 几章可以同时开着，来回对照不丢位置、不丢撤销记录。
- 没存的字不会在关标签页时不声不响地存掉或丢掉。
- 章节树只管整理：点卷不再把正在写的一章换成卷纲页。
- 工具栏少了一句几乎总是「已保存」的话。

**代价与已知上限**

- 正文少了一行（32）的高度；只开一章时这一行也在。
- 鼠标中键关标签页没有做：工具包不报中键（mygo v0.3.7；2026-10-13 升到 v0.4.8 以后也还没有）。
- 从检查、伏笔里一条条「查看原文」，每跳一章多一个标签页；靠「关闭其他」。
- 每个开着的标签页一个编辑器，内存跟着涨，没有量过上限，也没有设上限。
- 没在看的标签页在软件外面被改了，不会马上知道：切回来才读盘，那时直接换成盘上的字，不像正看的那一章会问「保留当前版本 / 使用磁盘版本」。它的字切走时已经存过，所以丢的只是外面改之前的那一版（开章时、定时的快照里还有）。
- 切回来发现盘上不一样而重新读的，撤销记录没有了。
- 同一章正看着再点它一次，还是从盘上重新读（撤销记录没有了），和以前一样。
- 问着存不存的时候按了换章的键（Ctrl+PgDn、Ctrl+Tab 这些），照换章的规矩先存了再走，那一问也跟着撤掉。
- 卷纲页没有编辑器，它的标签页只在章纲没存时算「没存」。
- 标签上的圆点和悬停的样子只在渲染的截图上看过，没有在真的窗口里点过。
