# Agent Note: 能点的原型放进仓库，纯 HTML/JS，不靠 Claude Design

Status: implemented

## Problem

设计稿（Design artifact）的画板是静止的，点不了。能点的原型做过两版（第 47、48 版），放在 artifact 里的 `Prototype.dc.html`：它要 Design 类型的运行库和同目录的组件文件才能开，只能在画布上点「播放」；改一处要先把最新版拉到本地、改、再发布。作者 2026-10-12 的要求是「不用 claude design，放在本地维护，随时修改」。

## Decision

- 原型在 `prototype/`，三个文件，没有库，不用构建，双击 `index.html` 就开：
  - `book.js`：那本假书（卷、章、设定、修改记录、伏笔、讨论、AI 的固定回复）。
  - `index.html`：样式。链的是 `../desk/tokens.css`，颜色、字号、间距只有那一份。
  - `app.js`：状态、每个动作做什么、每一块怎么画。
- 两个脚本都是普通 `<script>`，不用 ES module：从磁盘直接打开（`file://`）时浏览器会拦模块。`app.js` 整个包在一个函数里，免得里面的名字和浏览器自带的（`top`、`open`、`name`）撞上。
- 画法：只有一份状态 `S`。`set()` 改完状态，把整个窗口重新拼成一段 HTML，再由 `children()`、`patch()`（四十来行）对着页面上现有的节点，只改不一样的属性和字。这样输入框不会被重建（光标和拼音选字不断），正文里选中的字也不受打扰。有 `id` 或 `data-k` 的元素按名字认，别的按顺序对。
- 事件只在根上挂四个（点、打字、按键、右键）。元素上只留 `data-click="号码"`，号码对着这一遍画的时候登记的函数。
- 样式都写成类。只有跟着选中的字走的浮层（右键菜单、记伏笔、选回收哪条）在行内写 `left`、`top`。原型和代码一样守 `AGENTS.md` 界面那节的第 4 条。
- `npm run verify-prototype` 做两件事，改了 `prototype/` 就跑：
  - 设计规则。逐个文件查的那部分从 `scripts/verify-design.ts` 拆到 `scripts/design/check.ts`，设计稿和原型共用；原型对的是 `desk/tokens.css`，样式表里的每条规则也按控件高度查。顺手修了一处：`box-shadow:` 冒号后有空格时，写了变量也被报成写了数字。
  - 走查。`scripts/prototype/browser.ts` 用本机的 Edge 或 Chrome 无头打开 `index.html`（走 `file://`，和双击一样），经 DevTools 协议真的按鼠标、敲键盘；`walk.ts` 把 22 条流程点一遍，每条结束时还要查窗口里没有东西伸出去、页面没有报错。只用 Node 自带的 `WebSocket` 和 `fetch`。`SHOT=<目录>` 会存下每一步的截图。
- 它不进提交前的三道检查：要本机有浏览器，而且只有原型变了才有意义。
- 窗口固定 1266×780，和设计稿的总览一样大；浮层的位置从页面上量窗口、侧栏、右栏的宽，不另记数字。

## Alternatives considered

- **留在 Claude Design 里** — 原型和静止的画板共用同一套组件文件（侧栏、工具栏、正文、右栏标签），组件改了原型自动跟着变，不会两边对不上；作者在一张画布上看得到全部。不用：作者要的就是本地、随时改；那边每改一次都要拉取再发布，断网打不开，逻辑只能写成它的模板。
- **把 Design 的运行库和页面打成一个 HTML** — 几乎不用重写，和 artifact 那版一字不差。不用：运行库是 188 KB 的压缩代码，放进仓库看不懂也改不了；页面仍是 Design 的模板格式，「不用 Claude Design」只做到一半。
- **引一个小框架（Preact、Alpine 之类）** — 省掉自己写的对比更新，写法很多人认识。不用：从 CDN 引，断网就打不开；把副本放进仓库，又是一份别人的代码。这一页要的只是「整个重画，只改不一样的地方」，四十行够了。
- **每次直接整页重写，不做对比** — 最简单，一行 `innerHTML`。不用：输入框每敲一个字就被换掉，光标和拼音选字会断；正文里选中的字每次都丢，而右键菜单靠的就是它。

## Consequences

- **收益**：
  - 双击就开，改文件就是改原型：换内容改 `book.js`，调样式改 `index.html`，改行为改 `app.js`。
  - 每次改完一条命令验证，不用人盯着点。试过：把「记下」改成不存伏笔，走查停在那一步；把标题字号写成数字、把留白改成刻度外的数，规则检查都报出来。
  - 和 artifact 第 48 版逐张截图比过：布局一致，只有文字边缘的抗锯齿有细微差别。比的时候发现第 48 版在「修改记录」等几步之后整个窗口被横着滚走了八十多像素（窗口里有东西伸了出去）；本地这版没有，走查里每条流程都查。
- **代价与已知上限**：
  - 侧栏、工具栏、正文、右栏标签画了两遍：artifact 里的组件文件一遍，`app.js` 里一遍。设计稿改了这些组件，原型要手动跟。
  - 动作变了，`scripts/prototype/walk.ts` 里的步骤要跟着改；走查按字找东西点，改了文案也要改它。
  - 样式链的是 `../desk/tokens.css`，单把 `prototype/` 文件夹拷给别人打不开样子，要连 `desk/tokens.css` 一起。
  - 和之前一样：正文不能打字，AI 只回固定的几句。还点不了的有侧栏的「讨论」「作品分类」、新建章节、回收站、设置，正文上面的查找、更多、专注写作，「章纲」和「本章摘要」。
  - artifact 里的「原型」画板不再更新，留着还是删掉由作者定。
