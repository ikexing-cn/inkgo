# Agent Note: 两栏整块收起

Status: proposed

## Problem

2026-10-27 作者在软件里收起右栏，截了动到一半的样子，说「第一块是消散，第二块是向右隐藏，整体就很丑陋」。

软件现在照[页边批注](../../implemented/feature/2026-10-24-margin-notes.md)第 4 段做：右栏连同分隔线淡出、往右挪 24 像素（`kit.ColumnTravel`）；正文这边一下排成新的样子，编辑器整块按正文的位移往回挪（`slide`）。两样分开看都没错，合起来是两块：

- 右栏挪得少，主要是在原地变淡，标签行看着是「消散」。
- 右栏变淡，底下的东西透出来。编辑器整块挪，它右边的滚动条也跟着挪：开始时在右栏中间，200 毫秒里滑到窗口右边，从半透明的右栏里看得见。这就是「向右隐藏」的第二块。正文挪的是右栏宽的一半，滚动条也是，右栏自己只挪 24 像素，三样各走各的。

原型里也是几块各动各的，只是样子不同：批注有自己的 view-transition 名字，收起时自己往右退，不跟右栏走；标签页那一行、底栏没有名字，新旧两份叠着淡入淡出，字成了重影。

## Proposal

原型已经改了（`prototype/index.html` 的「收起、展开两栏」那一段、`base.js` 的 `moving`），`DESIGN.md`「动起来的地方」的挪动那条跟着改了。软件照原型做：

1. 栏整块进出。收起时侧栏往左、右栏往右，整块滑出窗口，滑过的距离是它自己的宽，画在窗口里，出了窗口边就裁掉；展开反过来从窗口边滑进来。不改透明度。标签、批注、分隔线都在这一块上，一起走。
2. 纸跟着栏边走，用同一条缓动。收起、展开都用 ease-out（`kit.Out`）：栏边和纸边要一起走，两条曲线不一样就会一前一后。现在离开用 ease-in，要改。
   - 和正文对齐的照旧整块平移：编辑器、标签页那一行、底栏左边那句（`slide`）。
   - 贴着纸右边的跟着栏边：底栏的备份和字数、编辑器的滚动条。滚动条不能再跟着编辑器按正文的位移挪：收起时它会躲在右栏下面，这一条还看不出来；展开时右栏从右边滑进来，滚动条按正文的速度走，只有栏边的一半，栏边在后面追它。
3. 别的一下排成新的样子。被栏盖着的，等栏让开才露出来。离开的右栏画在纸上面（现在就是），离开的侧栏画在纸下面（现在就是）；栏不透明，盖着的就看不见。
4. 顶上那一行下面的线不断开。展开右栏时纸已经窄了，右栏还没滑到，中间那一截原来没有线。原型在收起、展开时给 `.win-body` 垫一条整宽的线；软件里画在页面底下，或者让标签页那一行的线一直画到窗口右边、被右栏盖住。
5. 展开右栏时，批注随右栏整块进来，不再一条接一条地出来。换一章、从别的标签换到批注时照旧一条接一条。

讨论、大纲、检查这几页没有和正文对齐的东西，第 2 条只用在正文页；它们照第 3 条一下排成新的样子。

## Alternatives considered

- **还是淡出，只是标签行、批注、滚动条跟着右栏一起淡、一起挪** — 最强的理由：只挪 24 像素，动得少，画面安静，也不用裁边。没有用：只要变淡，底下的东西就透出来；纸那边挪的是右栏宽的一半，从半透明的右栏里看，还是两块在动，作者截的就是这个。
- **每一帧按当时的宽重新排版** — 最强的理由：每样东西自然贴着它该贴的边，不用一样一样地说谁跟谁走，讨论、大纲、检查这几页也一起顾到了。没有用：窗口不宽时正文栏比 36 个字窄，每一帧换一次断行，字在动画里来回跳，违反「字不跟着拉宽」；正文页每帧重排一章的字，在开发机上本来就只画得出三四帧（见页边批注那篇最后一段）。
- **离开的栏用 ease-in，进来的用 ease-out** — 最强的理由：这是常见的做法，离开先慢后快，进来先快后慢。没有用：纸边要贴着栏边走，纸的平移是 ease-out，栏用 ease-in 就和纸分开，中间露出一条空。

## Acceptance criteria

- 原型：收起、展开两栏，动到 40、100、160 毫秒截图，栏整块在走、不变淡，标签和批注不和栏分开；正文、标签页、底栏没有重影；展开右栏时顶上的线不断开。`npm run verify-prototype` 照旧过（它在减少动态效果下点，不看动画）。
- 软件：`go test ./desk` 的 `TestFoldingMovesThePaperAndRowsWithoutStretching` 改成查栏挪的是自己的宽、不改透明度，`TestUnfoldingDrawsTheProseWholeAndEasesIn` 改成两个方向都用 ease-out；加一条查展开右栏时滚动条贴着栏边、字数贴着栏边。`SHOT=<目录> go test ./desk -run ShotMotion` 截的收起右栏动到一半，右栏是半截露在窗口里、不透明。
- 作者在真窗口里看过。

## Risks

- 讨论、大纲、检查几页的东西一下就到新位置：检查页收起侧栏时，左边的列表一下往左移了侧栏那么宽，侧栏从它上面滑走。作者觉得跳，再照正文页的办法一样一样地说谁跟谁走。
- 整块滑出要在窗口边裁掉，栏也比原来多挪很多。页边批注那篇记过每帧的时间慢在平移过的裁剪区（mygo#794，v0.7.0 已改）；改完在开发机上看一次帧数。
