# Agent Note: 页边批注这一版界面

Status: proposed

## Problem

2026-10-24 作者让照 [oil-ui](https://github.com/oil-oil/oil-ui) 的做法试着改原型（这套做法后来装进了项目，见[界面设计照 oil-ui 的做法](../../implemented/process/2026-10-24-oil-ui-skill.md)）。

- 先做的轻改（按下、出现的动效，标题栏和侧栏换成白底）存在 `claude/oil-ui-tweaks`。作者说舒服了不少，但只是小修小改，要看完全改的样子，又加了纯纯写作的桌面版（writer.drakeet.com/desktop2）作参照。
- 三个方向里作者选了「页边批注」：查出来的不一致、埋下和回收的伏笔、要确认的设定，挨着它说的那一句写在页边，不再只在右栏的列表、底栏和检查页里。
- 第一版给作者看了，作者说是好设计，又有两处很不满：
  1. 右栏收起的按钮在右栏标签行的右端，收起以后「展开右栏」跑到了标题栏的工具里，点完要另找。
  2. 侧栏太杂，信息量太多：五行换页、带两个按钮的「章节」标题行、每一行的字数和页面图标、备份一行、回收站和齿轮。
- 以前的规则（`DESIGN.md` 和各篇笔记）多是作者一条条定的。作者这次允许在 worktree 里改 `DESIGN.md`。

## Proposal

规则已经写进 `DESIGN.md`，开头一条说明这一版只在原型里、软件还没跟上；作者没说过、是我定的几条标了「待作者确认」。这里写为什么，和以前的决定怎么接上。

### 各栏同一张纸

- 标题栏、侧栏、正文、右栏、设置左边那一列都用 `bg`，栏和栏之间只有 `line`。`side` 只给纸上隔出来的一块：引的原文、摘要、大纲里卷的那一行和下面的托盘。
- 标题栏下面不画线；侧栏顶上、标签页、右栏标签三行的底线是同一条。

### 两边的开关不挪地方

- 侧栏的开关在标题栏最左，右栏的开关在窗口按钮左边，两个对着。收起、展开是同一个按钮，在同一处；每一页都在，这一页没有那一栏就灰着。右栏标签行和大纲页工具栏里各自的那个按钮去掉。
- 写作页的工具里，时有时无的（续写的提示、本章伏笔、备份失败、待处理）在左，查找、专注两个图标在右：谁出来、谁走了都挤不动它们。没开着章时查找灰着，不拿掉。
- 专注写作时右栏的开关不画，只留它的位置，「退出专注」才在「专注写作」原处。
- 理由和 2026-10-13 侧栏开关不放在侧栏顶上是同一条，见[侧栏顶上](../../implemented/feature/2026-10-13-sidebar-top.md)：开关放在它收起的那一栏里，收起以后「展开」就得另找地方放。

### 标题栏正中换页

- 「讨论」「正文」「大纲」「检查」，正在的那一页墨色加粗，「检查」后面带条数；AI 关着时只有「正文」「大纲」。作品分类不常去，挪进「文件」菜单和设定的「更多」。书架上没有这一排。
- 专注写作时正中换成章名：正中一直说的是「在哪」。字数不跟着写，底栏有。
- 换页里有的几页不另写页名（检查页原来有一个大字「检查」）。顶上最深的当前项只留一处，是标签页；换页和右栏的标签，正在的那个只换成墨色，不加粗、不画线。

### 侧栏只列东西

- 顶上一行是作品名和一个加号（列章节时新建章节，讨论页上新对话）；下面是章节树，讨论页上是讨论。
- 章不带图标，卷带箭头；章名和卷名左边对齐，卷里的章再缩一级。字数、讨论的时间，指针移上去才出来。
- 后来照这一条，别处一列里每行都有的操作也是指针移上去才出来：作品分类的「编辑」「删除」，讨论每句回复下面那一行。
- 书架照评审试过去掉卡片的框、「更多操作」指针移上去才出来，作者看了说「这样分不清书哪一本是哪一本了」，改回原样。
- 挪走的：备份到底栏；新建文件夹、作品分类、回收站、设置进「文件」菜单（新建文件夹也在右键菜单里）；齿轮去掉。
- 以前 AI 开着时，大纲、检查、作品分类几页的侧栏列的是讨论；现在只有讨论页列讨论，别的页都列章节，点一章回到正文。
- 窄窗口不再把侧栏收成一列图标：换页、回收站、设置挪走以后，那一列只剩作品的方块和一个加号。改成侧栏 200、右栏 320、纸边 24，正文一行还有三十来个字。

### 底栏的备份

- 字数前面一项。好好的时候只写「已备份」，时间在悬停和点开里；在备份、失败、还没备份时照直写。开着右栏时写全「已备份 · 今天 10:32」，检查那一句就被挤成省略号。
- 放不下时先省字数，再省检查的那句。第一版反过来，窄窗口里「有 1 处待处理」被截成「有 1 处待…」，字数倒完整。

### 页边批注

- 右栏第一页是「批注」，打开一章就在这里（原型的 `notesOf`、`margin`、`placeNotes`）。一条批注记着第几段、第几个字起、几个字；照这个先后从上往下排，放在那一句的高度，挤不下的往下挪 8，正文滚动时跟着重排。
- 一条批注没有框：一道短线、一行小字说是哪一种（等作者处理的带琥珀色圆点，要确认的设定也算）、一行加粗的标题、一两行说明。开着批注时右栏左边不画线，像纸的页边。
- 指针移上去，正文里那几个字标出来（原型用 CSS 的 Custom Highlight，`::highlight(note)`）；反过来，指针在正文里画了线的字上，它的批注垫上底色。
- 等作者处理的几条在批注上就处理完，按钮和检查页、设定页是同一份（原型的 `checkActs`）；不改的（无需修改、忽略）在提示条上能撤销。点批注别的地方去看详情。
- 正文里画的线在页边都有它的批注。设定的名字平时不画线，指针移上去才出点线：[正文里标出设定的名字](../../implemented/feature/2026-10-19-names-in-the-prose.md)记过「名字的虚线和伏笔的点线看起来像」，一直等作者定；有了页边，线和批注对不上就更显眼。
- 「批注」标签不带数；「伏笔」标签的数改成原句已删加久未回收，和待处理里的「伏笔」同一个数。待处理里检查来的那一组从「设定不一致」改叫「检查」：里面还有名字有误、新出现。
- 待处理的「全部忽略」照[待处理](../../implemented/feature/2026-10-09-pending-list.md)只是不再列在待处理里。第一版的批注跟着忽略一起不见了，正文里的线、底栏、「检查 5」却还在；现在批注跟着检查结果走，忽略也能在提示条上撤销。
- AI 关着时只有伏笔的批注。

### 标签页

- 标签只有名字（卷带文件夹图标），正看的那个墨色、下面一道墨线，和右栏的标签同一种；格子和格间的竖线去掉。最左的 ‹ › 留着。

### 动起来的地方

- 按下、出现、挪动三种，都在 0.25 秒以内；系统设了减少动态效果就直接到位（`DESIGN.md`「动起来的地方」）。点击检查在减少动态效果下跑，量的是停下来的样子。
- 挪动是评审要的：收起、展开两栏时正文一下跳到新位置，看不出从哪来；处理掉的批注一下就没了。原型用浏览器的 View Transitions（`base.js` 的 `moving`，样子在 `index.html`），正文平移、字不拉宽，收起的那一栏往它那边退，处理掉的批注往页边退。

### 独立评审

照 oil-ui 的做法派了一个只看截图、不看代码的评审，按「全新界面与改版评审」打 7 分：方向成立，扣分最重的是点了「全部忽略」以后各处说法打架。照它的清单改了上面几处，另外：

- 窄窗口：讨论页的纸边跟着窄（80 → 24），每句回复下面那一行放不下时截断；右栏搜索框能缩，「更多」不再被切掉。
- 删掉设置里「沿用讨论模型」旁边那句「与讨论使用同一模型」，讨论回复下的圆形头像只留一个记号。
- 标签行、底栏和正文从同一条线起（40，窄窗口 24）；批注的字和右栏的标签对齐。

第二轮还是 7 分，上一轮的问题都没再提，扣在更深一层：

- 「采纳」不能撤销；采纳了林晚的设定从本章起的变化，同一处的「与设定不一致」还挂着、还引着旧设定。现在采纳也有提示条能撤销，这一章拿这条设定对照出来的不一致一起拿掉。
- 「设定待确认」的标题从「关于 林晚」改成「林晚的设定从本章起有变化」；类别那行小字从 `faint` 换成 `muted`（`faint` 在白底上不到 3:1）。
- 收起一栏后正文居中了，标签行和底栏还在左边：两样跟着正文栏的左线走。
- 收起、展开时新旧两种断行叠成重影：收起展开时正文只挪新的那一份。批注错开出来，最后一条也在 0.25 秒里停下。
- 大纲的卡片不再常驻阴影（`DESIGN.md` 阴影只给浮着的）。
- 提示条从右上角挪到右下角：处理批注以后的提示条会盖住右栏顶上的搜索和「更多」，原型检查就是点「更多」点到了提示条上。

到这里停下，没有再评第三轮：剩下的几条（下面的 Alternatives）要么是作者定过的样子，要么要作者先回答产品上的问题，再评一轮也还是这几条。

没照评审改的，写在下面的 Alternatives。

### 软件里怎么跟上（作者确认原型以后）

- `desk/titlebar.go`：正中换页，右栏的开关和侧栏的对着，工具里的先后，专注写作时只剩章名、工具、窗口按钮。
- `desk/shell.go` 的 `sidebar`：作品名加一个加号、章节树；窄窗口不再有图标栏。`desk/write.go` 的底栏加备份。
- `desk/pane.go`：「批注」一页。批注的高度用 `editor` 的 `RangeBox(a, b)`，它已经能报一段字在编辑器里的位置；滚动时重排。
- `DESIGN.md` 里列的 `go test ./desk` 有几个查的是旧样子（`TestTheTitleBarHasItsOwnRow`、`TestTheSidebarIsPutAwayOnEveryPage`、`TestMenuRowsOffThePageOfProse` 等），跟着改；`SHOT=<目录> go test ./cmd/inkgo` 截出来和原型对。

分四段跟，每段交给 Codex 做、审过再合：

1. 2026-10-26 已跟上：各栏同一张纸、标题栏（正中换页、两边的开关、右边的工具、专注写作只剩章名）、侧栏只列东西、标签页那一行、窄窗口不再收成图标。
   - 一行最多 36 个字放进了编辑器自己排（`editor.TextColumn`），编辑器照旧铺满正文区。第一版在编辑器外面套框限宽，滚动条跑到了正文旁边，窄窗口里被剪掉，两边空白处滚不动。
   - 「正文区至少 480」用侧栏这一刻的宽度算，窄窗口默认右栏 320 时照旧成立。
   - 侧栏的备份那一行拿掉以后，`desk/backup_test.go` 几条暂时查的是内部状态，第二段备份进了底栏再改回点界面。
2. 底栏的备份、能撤销的提示条、指针移上去才出来的东西、几页的小改。
3. 页边批注。
4. 动起来的地方。

## Alternatives considered

- **轻改：只换白底、加动效，别的不动**（`claude/oil-ui-tweaks`）。
  - 最强的理由：改得少，作者一条条定下的规则几乎都不用动，软件跟上也快。
  - 没有用：作者看了说只是小修小改，要看完全改的样子。
- **方向一「一张纸」：只有标题栏和正文，章节、设定、讨论做成从两边滑出来、盖在正文上的抽屉**。
  - 最强的理由：最像纯纯写作，正文最安静。
  - 没有用：作者选了页边批注。设定和待确认的事不再一直看得见，而查出正文和设定对不上正是 Inkgo 最特别的地方。
- **方向三「左右两张纸」：右栏换成第二个编辑区，设定、章纲、别的章摊开和正文对照**。
  - 最强的理由：对照写作最顺手，Ctrl 点一个名字就翻到她的设定页。
  - 没有用：作者选了页边批注；设定从一张清单变成一页一页，要靠搜索找。
- **右栏的开关留在右栏标签行的右端，收起以后在下面那一行的右端原处放「展开」**。
  - 最强的理由：开关挨着它管的东西，标题栏少一个图标。
  - 没有用：讨论、大纲几页顶上那一行各不一样，「原处」要一页一页地找，有的页也不一定有那一行；和 2026-10-13 侧栏开关不放在侧栏里是同一个理由。
- **专注写作时右栏的开关灰着，和书架上灰着的侧栏开关一样**。
  - 最强的理由：一条规则管到底，「这一处没有那一栏就灰着」。
  - 没有用：专注写作只留正文，多一个点不动的图标是噪音；留着位置已经够让「退出专注」不挪。
- **换页留在侧栏，收成顶上一排小字**。
  - 最强的理由：侧栏还是「去哪儿」的地方，标题栏不添东西。
  - 没有用：侧栏收起就没法换页；放在标题栏正中，每一页、侧栏收没收都在。
- **章节树照旧写每一章的字数**。
  - 最强的理由：作者常看各章的长短调节奏。
  - 没有用：作者说信息太多。指针移上去就出来，开着的那一章底栏也有。
- **备份留在侧栏最下面一行**。
  - 最强的理由：每一页都看得到，不只正文页。
  - 没有用：作者要侧栏只列东西。代价写在 Risks 里。
- **窄窗口照旧把讨论页的侧栏收成一列图标**。
  - 最强的理由：讨论要留出能读的宽度，这是以前收成图标的原因。
  - 没有用：东西挪走以后那一列没什么可放；两栏一起窄一些，正文、讨论都有三十来个字一行。
- **标签页照旧一格一格、格间竖线**，[章节标签页](../../implemented/feature/2026-10-13-chapter-tabs.md)是照作者说的参考 VS Code 做的。
  - 最强的理由：作者自己要的样子，哪个是正看的一眼就清楚。
  - 没有用：各栏同一张纸以后，格子和竖线是那一行唯一的框；只留名字和墨线，和右栏标签同一种。作者 2026-10-25 确认照这一版。
- **侧栏收起后，正文和页边作为一对居中**（评审）。
  - 最强的理由：现在左边空 132、右边只空 26，批注几乎贴着窗口边。
  - 没有用：右栏是贴着窗口右边的一栏，开关在它上面、宽不超过 390，都是作者要的；要居中，右栏就得离开窗口边，右边再空出一块。
- **「全部忽略」先问一句再忽略**（评审给的两种做法之一）。
  - 最强的理由：一次 8 条，点错之前就拦住。
  - 没有用：每次都多点一下；提示条上能撤销，点错了一步回来。
- **名字换一种线（实线、换颜色），一直画着**。
  - 最强的理由：名字一直看得见，作者知道能点。
  - 没有用：正文里已经有伏笔的点线、查出来的虚线、AI 写的浅下划线，再多一种更难分；名字是去设定的路，不是批注。
- **「落点」换一个不用解释的名字，删掉那句说明**（评审）。
  - 最强的理由：一个名字要靠一句说明才懂，是名字没起好。
  - 没有用（这一次）：「落点」是作者定过的叫法，`DESIGN.md` 表单那一条就引着「现在的落点是“设定库”」；换名字留给作者，说明先留着。
- **讨论页换掉气泡**（评审说讨论页像网页 AI 聊天）。
  - 最强的理由：讨论页和正文页不像同一个软件。
  - 没有用：气泡是作者定过的样子（圆角 `dialog`）；评审也说不用加东西，这一次只去掉头像的圆、收起每句下面那一行。
- **把待确认的设定也算进待处理**（第二轮评审：页边两个琥珀点，底栏和待处理的「本章」只说 1 处）。
  - 最强的理由：琥珀色说的是等作者处理的事，屏上的琥珀点和数应该对得上。
  - 没有用（这一次）：待确认在这一版以前就带琥珀点、不进待处理，[待处理](../../implemented/feature/2026-10-09-pending-list.md)只收检查、伏笔、备份。算不算进去是作者的事，等作者定。
- **讨论页、大纲页改成和正文同一张纸**（第二轮评审）。
  - 最强的理由：遮住字看，这两页还是通用 AI 聊天和表格的样子。
  - 没有用：讨论的气泡、大纲的实线框和虚线框都是作者定过的；这一次只拿掉了大纲卡片常驻的阴影。
- **结构大改第一轮：「一张纸」（目录是抽屉、别的都是命令）、「书和稿」（书层一张全书的图，伏笔画成章与章之间的线）、「左边一条轨」（一列格子，同时只开一栏）**。作者说侧栏还是太多、以后功能会越堆越多，要改得再大一点，做了这三个首屏。
  - 最强的理由：每个都给了「新功能放哪」一条规则，「书和稿」还给了整本书一张图，三套导航（换页、右栏标签、目录树）收成一套。
  - 没有用：作者看了说都很一般。三个用同一套黑白和字体，只换了东西摆的位置，没有一处是 Inkgo 自己才有的。

## Risks

- 作者说的「侧栏太多、以后功能会越堆越多」还没解决：两轮结构大改都没要，新功能仍要在换页、右栏标签、目录树三处里挑一处放。
- 备份失败只在正文页报（标题栏的「备份失败」和待处理）：在讨论、大纲、检查页时看不到，直到回正文页。
- 换页在标题栏正中，窄窗口里本章伏笔、备份失败、待处理同时出来时，可能挨上它。
- 一章的批注多了（十几条）会一路往下挪，离它说的那一句越来越远；原型只有三条，没试过多的。
- 不显示字数，习惯看各章长短的作者要多移一下指针。
- 原型的批注悬停用浏览器的 Custom Highlight；软件里要用编辑器自己的 `TextRanges` 或底色来标，样子可能有出入。Custom Highlight 不能渐变，所以原文的底色是一下出来的，只有批注的底色 0.1 秒浮起。
- 挪动在原型里靠浏览器的 View Transitions；mygo 里要自己在几帧里插位置，没做过，可能做不到原型的样子。
- 名字平时不画线，作者可能不知道名字能点；设置「外观」里「正文中标出设定的名字」的意思也跟着变了（现在是指针移上去才标）。
