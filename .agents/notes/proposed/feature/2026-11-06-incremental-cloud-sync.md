# Agent Note: 增量云同步，以及原子写文件和它的关系

Status: proposed

## Problem

作者提过多台机器之间的云同步，2026-10-21 搁置，当时留下三个要先查清的问题：同一章在两台机器上都改了怎么合，各目录的 `.order` 怎么办，要不要端到端加密。

2026-11-06 盘点到[第 8 条](../architecture/2026-11-06-reinvented-wheels.md)（`internal/atomicfile`）时，作者问原子写文件有什么好处，并说后续可能有「增量云同步」。作者说：「原子写文件和增量云同步都先记笔记」。本篇只记下目前知道的事实和要想清楚的问题，不定方案，暂时搁置。

## Proposal

### 原子写文件现在做什么

- `internal/atomicfile` 在目标文件的同一目录建一个临时文件 `.tmp-<随机>`，写完 `Sync`、关闭，再改名盖掉原文件。`workspace` 的整文件写入都经它（`store.go` 362 行），另外设置、书架、模型配置、扩展的书级状态、备份、导出、目标页也在用。
- 好处：写到一半断电、崩溃或磁盘满，原文件还是完整的旧版本，不会出现半截的章节或半份 `work.yaml`。读的一方（包括别的程序）只会看到旧的或新的整份文件。
- 没有合适的现成库替代：`google/renameio` 在 Windows 上不导出任何函数，`natefinch/atomic` 已停更。

### 原子写和同步的关系

- **它是同步的前提**：同步客户端（不管是我们自己的，还是作者放在网盘目录里的第三方客户端）只要读到的是整份文件，就不会把半截的稿子传到别的机器上。
- **临时文件会被第三方客户端看见**：`.tmp-` 文件在书的目录里，存在的时间很短，但网盘客户端可能把它也传上去，或者在别的机器上留下一个空的临时文件。自己做同步时要排除 `.tmp-*`；作者用第三方网盘时，这一点值得在帮助里说一声。
- **章节是整文件替换的**：改一个字，整章重写。对同步来说，最小单位是一章，「增量」最自然的粒度是「只传变了的章」，不是章内的字。
- **JSONL 本来就是增量的**：讨论记录、修订历史等追加日志（`workspace/jsonl.go`）是在文件末尾追加，带游标和前缀长度，只追加不重写。按前缀长度传新追加的部分，就是天然的增量。
- **冲突从现有的版本核对出发**：`WriteChapterOver` 在写之前比对上次看到的时间戳，外面改过就不盖掉，交给作者处理。同步拉下来的改动在本机看来就是「软件外面改了」，现有的提示和处理能直接接上；[文件监视扩展](2026-11-06-watch-files-extension.md)能让它更快被发现。

### 要想清楚的

- **两台机器都改了同一章**：现在的核对只能发现冲突，不会合并。要不要做段落级的三方合并，还是只让作者在两份之间选。
- **JSONL 两边都追加**：两台机器各自往同一个日志追加，文件级的同步会冲突。要么同步层按行合并，要么每台机器写自己的日志文件。另外，追加之前 `cursor` 会重新核对：文件从外面变长了，先校验前缀的哈希、把新追加的行读进来；`writeJSONL` 再按这个前缀写，长度对不上时截回前缀，本意是丢掉写了一半的最后一行。所以外面追加的行只在「核对完、还没写」这一小段时间里可能被截掉。同步客户端随时会写文件，这个窗口要不要关掉，做同步时要核对。
- **`.order` 和改名、移动**：两边各自调了章节顺序或移动了章节，怎么合。
- **一本书只许一个程序写**：`workspace.Store` 的约定是同一时刻只有一个程序写一本书。两台机器同时开着同一本书，等于两个写入方，要定是加锁、按机器分开，还是允许并发再合并。
- **端到端加密**：要不要，对增量（只传变了的部分）有什么影响。
- **和订阅的关系**：作者 2026-10-21 想先定商业模式，再做服务端的工作。这一条仍然成立。

## Alternatives considered

- **只靠第三方网盘同步书的目录。** 最强的理由是什么都不用做，书本来就是纯文件。问题就是上面那几条：两边都改时只会多出一份冲突副本，JSONL 和 `.order` 没人合，`.tmp-` 文件可能被传上去。作者现在就可以这么用，本篇不拦。

## Acceptance criteria

本篇搁置，没有施工的验收。重新拿起来时，先回答「要想清楚的」里每一条，再写方案。

## Risks

- 同步一旦做了，`workspace` 里「一个写入方」的假设就不再成立，读写、游标、缓存都要重看一遍。
- 第三方网盘的行为（改名、冲突副本、延迟）各家不一样，没法全测。
