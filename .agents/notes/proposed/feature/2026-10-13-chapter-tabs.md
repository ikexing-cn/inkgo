# Agent Note: 正文多标签页，保存状态改成标签上的圆点

Status: proposed

## Problem

作者 2026-10-13 看软件时说了两件事：

- 「我发现个很大的问题，我们没有多标签页」。现在一次只开一章：写第 87 章时想对照第 84 章，点过去，第 87 章就被换掉了，只能靠侧栏顶上的 ‹ › 来回。
- 顶栏章节名后面那句「已保存」，「这个形式我不太喜欢」。没有说想要什么样的。

按 `AGENTS.md` 界面那节第 2 条，原型里没有的界面先在原型里做出来给作者看。这一篇记的是原型里做成的样子，作者确认后再写代码。

## Proposal

原型已经改了（`prototype/write.js` 的 `go`、`shutTabs`、`toolbar`，样式是 `.sheets`、`.sheet`；`.tabs`、`.tab` 是右栏那一排，已经占了）：

- 顶栏下面多一行标签页，照 VS Code 的样子：一格一个，是一章（或一卷的卷纲），格子之间一条竖线，左边是文稿或文件夹的图标，右边是关闭的叉。这一行是侧栏那种浅灰底，正看的那格是正文的白底、字加粗，行底下的线到它那里断开，和正文连成一片。
- 顶栏不变：左边还是「卷名 › 章名」，右边是功能按钮。专注写作时标签这一行收起。
- 打开一章：已经有它的标签页就切过去，没有就在正看的那个右边开一个。从章节树点、从检查和伏笔的「查看原文」跳过来、‹ › 都一样。
- 点章节树里的卷不开标签页，只是折起、展开（作者 2026-10-13：「点目录不应该打开标签页，目录只负责左侧的管理」）。卷纲那一页还在，从卷的右键菜单「编辑卷纲」打开，这时才有它的标签页。在卷上右键「新建章节」建在这一卷的末尾：以前是先点开这一卷再建，现在点它不算「开着这一卷」了。
- 关闭：标签上的叉（正看的那个一直有，别的指针移上去才显出来，位置一直留着）、鼠标中键、Ctrl+W；标签上右键有「关闭 / 关闭其他 / 关闭右侧」。关掉正看的，换到右边那个，没有就左边；一个不剩时正文是空的那一页（「从左侧选择一章开始写作」），这时按 ‹ 回到刚关掉的那一章。
- Ctrl+Tab / Ctrl+Shift+Tab 换到下一个 / 上一个标签页。（原型开在浏览器里，Ctrl+W、Ctrl+Tab 被浏览器拿走，只写进了快捷键表。）
- 标签跟着名字的长短，最宽 200，不压窄：名字一直看得全。排不下时整排左右滚（滚轮），正看的那个总在看得见的地方。
- 一章进了回收站，它的标签页跟着关掉。
- 保存状态：不再写「已保存」。没存的那一章，标签上关闭的叉换成一个圆点，指针停上去的提示里写「未保存」；存好了圆点就没了。Ctrl+S 的提示「已保存」还在。原型的正文现在能打字，圆点可以真的打出来看：停笔 1.5 秒消失。

写代码时要定的（原型里是假的）：

- 每个标签页留着自己的编辑器：撤销记录、光标、滚到哪。切走时照现在换章的做法先存。
- 开着哪几个标签页、正看哪个，记在作品里，下次打开还在。
- 在软件外面被改了或找不到了的那一章，它的提示条只在看它的时候出现。

## Alternatives considered

- **点章节树仍在当前标签页里换章，要同时开着才「在新标签页打开」（Ctrl+点、中键、右键菜单），和浏览器、Obsidian 一样** — 随手翻章节不会攒出一排标签，不想用标签页的人什么都不用学。没有选：只点章节树永远只有一个标签，看上去和没有标签页一样，要先知道 Ctrl+点才用得上；作者要的是一眼能看懂。这一条如果作者更想要，改的只是 `go` 里「没有就新开」那一句。
- **VS Code 那样的预览标签：单击开的标签会被下一次单击替换，双击或在里面打了字才留住** — 两头都顾到，翻章节不攒标签，要留的又留得住。没有选：「这个标签是临时的」要用斜体之类的样子告诉人，中文斜体难看，规则也要解释一遍才懂。
- **标签放在顶栏里，替掉「卷名 › 章名」，做成圆角的小块** — 不多占一行，正文高度不变。这是第一版，作者 2026-10-13 看了以后不要：「标识性不够强，每个标签页之间没有切割，标签页和功能按钮拥挤而且都位于 header」，让参考 VS Code。右栏开着时顶栏只有中间一栏宽，标签和按钮确实挤在一起。
- **「已保存」挪到底栏字数旁边** — 想确认存没存的人一直看得到。没有选：停笔片刻就自己存，绝大多数时候它写的都是「已保存」，一直占着地方；出问题时（存不上）本来就有提示。

## Acceptance criteria

- 点章节树里的卷，标签页不变；右键「编辑卷纲」才多一个。
- 点三章，顶栏有三个标签页，点标签在它们之间切换，各自的光标和滚动位置都还在。
- 打字后正看的标签上出现圆点，停笔后消失；顶栏里没有「已保存」「未保存」这几个字。
- 叉、中键、Ctrl+W、右键菜单的三项都能关；关到一个不剩是空页，‹ 能回来。
- 开十几个标签页，窗口里没有东西被挤出去，正看的标签看得见。
- 关掉软件再打开，标签页还是那几个。

## Risks

- 从检查、伏笔里一条条「查看原文」，每跳一章多一个标签页，会攒得很快。先靠「关闭其他」；真嫌多再看上面第一、二种做法。
- 正文少了一行（32）的高度；只开一章时这一行也在。
- 右栏开着时中间一栏放得下四五个标签，再多就要滚。
- 每个标签页一个编辑器，开得多了内存跟着涨；现在一章的编辑器不大，没有量过上限。
