# Agent Note: 拼字

Status: proposed

## Problem

网文作者靠日更吃饭，常用「拼字」逼自己写：定一段时间，比如 25 分钟，埋头写，到点看写了多少。在作者圈里，拼字多半是几个人进同一个房间、同时开始、比谁写得多。

软件里现在有每日目标和「最近 7 天」，在底栏字数旁的浮层里，见[正文页](../../implemented/feature/2026-10-08-writing-page-and-chapters.md)。但没有「这一段时间」的概念：作者要自己看表、自己记开始时的字数。

2026-10-21 作者同意先做一个人的拼字，写成提案。多人拼字要账号和服务器，等订阅定了再说。

## Proposal

先做一个人的拼字，不联网，AI 关着也能用。

### 开始

- 底栏字数旁的浮层，「每日目标」上面加「拼字」。
- 选时长：15、25、45、60 分钟，或者自己填。
- 目标字数选填：填了，到字数就算完成；没填，到时间算完成。
- 点「开始」进专注写作，也可以不进。这一项记住上次的选择。

### 进行中

- 底栏字数那里换成「拼字 18:32 · +640 字」：剩下的时间和这一段写了多少。
- 字数的算法和「今日字数」一样，按全书字数的变化算，删了字会减。
- 中途能「结束」。提前结束也记下来，写「提前结束」。
- 拼字开着时换作品、回书架、关窗口，先问一句，标题是「是否结束拼字」。

### 到点

- 右上角的提示条写「拼字结束：25 分钟写了 1,240 字」，带「再来一次」。不响铃。
- 浮层的「最近 7 天」下面加「最近的拼字」，列几条：哪天、多长、写了多少字。

### 小黑屋（可选）

- 开始时可以勾「写完才能离开」。勾了以后，专注写作退不出来，Esc 不起作用，到点或到字数才放开。
- 关窗口仍然能关，但要先问一句，并且记成「提前结束」。
- 只管这个软件，不锁电脑上别的程序。

### AI 写的字算不算（待作者确认）

拼字比的是作者自己写了多少。拼字期间采纳的 AI 提议、按 Tab 接受的续写，不算进这一段的字数；今日字数照旧算。

### 存在哪

- 拼字记录和每日字数放在一起：本机的 `.writer/desk.json`，按作品分开。
- 一条记录有开始时间、计划时长、实际时长、目标、写了多少字、是否提前结束。
- 以后做多人拼字，房间里每人交的就是这样一条。

样子要先在原型里做出来给作者看（`AGENTS.md` 的规矩）：浮层里的「拼字」、进行中的底栏、到点的提示条、小黑屋、「最近的拼字」。

## Alternatives considered

- **一开始就做多人拼字**。
  - 最强的理由：作者圈里说的拼字本来就是多人的，有人一起比，才逼得动自己；这也是付费、留住作者的好理由。
  - 没有用（这一期）：要账号、服务器、房间、实时同步，订阅还没定。一个人的版本先把计时、计字、记录做对，多人版用同一种记录。
- **小黑屋锁住整台电脑**，全屏且切不出去，像一些码字软件那样。
  - 最强的理由：真的逼得住，切不出去刷手机以外的东西。
  - 没有用：要系统权限，Windows、Mac 做法各不相同；软件一出错，作者就被锁住了；而且它对付不了手机。只管这个软件已经够提醒自己。
- **按键数或打字速度算**。
  - 最强的理由：删了重写也是在写，按键数更能反映花了多少力气。
  - 没有用：作者之间比的是字数，日更看的也是字数；和「今日字数」用同一种算法，作者不用想两种数。
- **拼字时 AI 写的字也算**。
  - 最强的理由：算法简单，和今日字数完全一致。
  - 没有用：拼字是逼自己写，AI 的字算进去，数字就不说明问题了。这一条待作者确认。

## Acceptance criteria

- 原型：
  - 浮层里的「拼字」：时长、目标、开始；
  - 进行中底栏的倒计时和字数；
  - 到点的提示条和「再来一次」；
  - 提前结束；
  - 小黑屋时 Esc 不起作用、关窗口先问；
  - 「最近的拼字」；
  - 采纳 AI 提议不算进拼字的字数；
  - `npm run verify-prototype` 有对应的步骤，时间用走查的假时钟走过去。
- `go test ./desk`：同样的几处，加上记录写进 `.writer/desk.json`、重开作品还在、AI 关着时照常能用。
- DESIGN.md 加一条拼字的规则，比如进行中底栏怎么写、到点怎么提示。

## Risks

- 开着拼字时电脑睡眠、或软件被强行关掉，时间怎么算：按实际经过的时间算，到点时软件没开着的，下次打开时记成「中断」。
- 「AI 写的字不算」要分清哪些字是 AI 的：采纳提议和接受续写的那一刻记下字数。作者采纳以后又改了，就不再细分。
- 小黑屋会让作者觉得被软件绑架。默认不勾，关窗口永远能关。
